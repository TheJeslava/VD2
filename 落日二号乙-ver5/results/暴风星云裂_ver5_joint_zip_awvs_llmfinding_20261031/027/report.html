F-1 027.php ping 功能通过 $_REQUEST['ip'] 拼接 shell_exec 导致命令注入

critical command_injection / CWE-78 · 置信度 0.93 · candidate / externally_corroborated

位置：027.php:5-23

脚本在 $_POST['Submit'] 存在时，从 $_REQUEST['ip'] 读取用户输入（第 5 行），仅用黑名单 str_replace 删除 '&&' 与 ';'（第 8-14 行），随后直接拼接进 shell_exec('ping -c 4 ' . $target)（第 23 行，Windows 分支为第 19 行）。黑名单不覆盖管道符 |、反引号 `、$()、换行符、& 单字符、|| 等，攻击者可在 ip 参数中注入任意命令并以 Web 进程权限执行，构成远程命令执行。

影响：未认证攻击者可在服务器上以 Web 进程权限执行任意系统命令，完全控制主机，读取敏感文件、横向移动。

CVE/CWE 论证：CWE-78 OS 命令注入。source（$_REQUEST['ip']）到 sink（shell_exec）链路在 CODE PACK 内完整闭合，黑名单可被 '|' 等字符绕过，无需认证即可外部触发。

修复建议：不要将用户输入拼接进 shell 命令；使用 escapeshellarg($target) 转义，或改用白名单校验 IP 格式（filter_var($target, FILTER_VALIDATE_IP)），并避免使用 shell_exec 执行外部命令。

F-2 027.php Windows 分支 ping 命令拼接导致 OS 命令注入（CWE-78）

critical command_injection / CWE-78 · 置信度 0.83 · candidate / rule_verified+llm

位置：027.php:17-19

攻击者通过 HTTP 查询参数 `ip` 提供输入，该输入在 027.php:5 被读入变量 `target`（证据中 source 标注为 query `ip`）。程序在 027.php:17 用 `stristr(php_uname('s'), 'Windows NT')` 判断运行平台，命中 Windows 分支后，在 027.php:19 将 `target` 直接字符串拼接到 `shell_exec('ping ' . $target)` 中执行。代码片段显示拼接前没有任何转义、白名单或参数化处理（无 escapeshellarg/escapeshellcmd、无 IP 格式校验），因此 `target` 中的 shell 元字符（如 `&`、`|`、`;`）会被命令解释器当作命令分隔符执行，校验完全失效。

影响：远程未认证攻击者可在 Web 服务器进程权限下执行任意系统命令，导致服务器被完全控制（RCE）、敏感文件读取、内网横向移动与持久化。Windows 分支下可通过 `&`、`|` 等分隔符追加任意命令。

CVE/CWE 论证：CWE-78（OS 命令注入）：外部可控输入 `ip` 未经净化直接进入 `shell_exec` 命令字符串，利用链闭合（source 027.php:5 → sink 027.php:19），通过普通 HTTP GET 即可触达，无需认证。该分支仅在 `php_uname('s')` 含 'Windows NT' 时执行，属环境相关可达性，不影响漏洞成立。

修复建议：不要用 shell 拼接执行 ping：改用参数数组形式（如 `proc_open`/`exec` 传数组）或 PHP 原生 socket 实现连通性检测；若必须调用外部程序，对 `target` 做严格白名单校验（仅允许合法 IPv4/IPv6/域名正则），并使用 `escapeshellarg()` 包裹参数，同时以最小权限账户运行 Web 服务。
