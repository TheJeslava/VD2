F-1 011.php 登录接口 username 参数 SQL 注入（可绕过认证并拖库）

critical sql_injection / CWE-89 · 置信度 0.95 · candidate / llm_inferred

位置：011.php:5-13

011.php 第 3 行通过 $_GET['Login'] 触发登录分支，第 5 行直接取 $_GET['username'] 赋给 $user，未做任何转义/参数化；第 12 行把 $user 直接拼接进 SELECT 语句，第 13 行交给 mysqli_query 执行。password 虽经 md5() 处理（第 9 行），但 username 完全可控，攻击者可用 ' OR '1'='1 之类的 payload 改变 SQL 语法，绕过密码校验以任意用户（含管理员）身份登录，或用 UNION/布尔/报错注入读取 users 表全部数据。第 13 行的 die(mysqli_error(...)) 还会把数据库错误回显到页面，构成报错注入通道。

影响：攻击者可绕过登录认证以任意用户身份进入受保护区域，并通过 UNION/报错注入读取 users 表全部账号密码哈希，进而横向接管账户；若数据库账号权限较高，还可进一步读取其他库数据。

CVE/CWE 论证：CWE-89 SQL 注入。外部 GET 参数 username 未经转义直接拼接进 SQL 并由 mysqli_query 执行，链路在单文件内闭合，无需认证即可触发，属于典型可申报 CVE 的注入漏洞。

修复建议：改用预处理语句（mysqli_prepare + bind_param 或 PDO 参数绑定）；对 username 做类型与长度校验；关闭 die(mysqli_error()) 的错误回显，改为记录日志并返回通用错误；密码校验应使用 password_hash/password_verify 而非 md5。

F-3 011.php 口令使用 MD5 哈希（CWE-328）

medium weak_crypto / CWE-327 · 置信度 0.76 · candidate / rule_verified+llm

位置：011.php:8-9

011.php:8 从 $_GET['password'] 读取口令，011.php:9 直接调用 md5($pass) 生成摘要，并在 011.php:12 的 SQL 中与数据库存储值比较。MD5 为快速、无盐、无迭代的弱哈希，用于口令存储/校验属不安全实现；攻击者获取数据库后可借助彩虹表或 GPU 高速碰撞还原口令。注意：此处是哈希算法强度问题（CWE-328），不是加密算法模式问题。

影响：口令摘要可被离线快速破解，导致用户口令泄露；若用户跨系统复用口令，可进一步横向利用。

CVE/CWE 论证：CWE-328：MD5 被用于口令等安全用途，算法本身抗碰撞与抗暴力能力不足；该弱点为代码实现型，无需 HTTP 污点链即可成立，证据为 011.php:9 的 md5( $pass ) 原文。

修复建议：改用 password_hash()（PASSWORD_BCRYPT/ARGON2ID）生成带盐慢哈希，校验用 password_verify()；迁移期可对旧 MD5 值做一次重哈希升级；禁止在 SQL 中直接比较明文或裸 MD5。

F-4 011.php 登录成功后 username 反射型 XSS

medium xss / CWE-79 · 置信度 0.7 · candidate / llm_inferred

位置：011.php:21-22

登录成功后，第 21 行把 $user（来自 $_GET['username']，第 5 行）直接插入 HTML 字符串 $html 并输出，未做 htmlspecialchars 等编码。虽然要走到该分支需先通过第 15 行的 mysqli_num_rows==1 判定，但结合上面的 SQL 注入（username 用 ' OR '1'='1 使查询返回行），攻击者可让 $user 携带 HTML/JS 片段并被原样渲染，形成反射型 XSS。第 22 行 $avatar 来自数据库，若 avatar 字段可被写入也可形成存储型 XSS，但当前代码包无法确认写入点。

影响：可在受害者浏览器执行任意 JS，窃取会话/凭据或发起 CSRF 操作；若管理员访问该链接可导致后台被操控。

CVE/CWE 论证：CWE-79 反射型 XSS。username 未编码输出到 HTML，链路依赖 SQL 注入使登录分支可达，整体在单文件内闭合。

修复建议：输出前对 $user 使用 htmlspecialchars($user, ENT_QUOTES, 'UTF-8')；对 avatar 做 URL/属性编码校验；修复 SQL 注入以消除前置条件。
