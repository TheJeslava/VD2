F-1 022.php 口令更新处 SQL 注入（CWE-89）

critical sql_injection / CWE-89 · 置信度 0.68 · candidate / rule_verified+llm

位置：022.php:42-44

攻击者通过 HTTP 请求向 022.php 提交修改口令的表单，外部输入在 022.php:25 被读入变量 $pass_new（候选 source 记为 query `password_new`）。该值在 022.php:38 仅经过 mysqli_real_escape_string 处理，随后在 022.php:43 被直接拼接进 SQL 语句：$insert = "UPDATE `users` SET password = '" . $pass_new . "' WHERE user = '" . $current_user . "';"，并在 022.php:44 交由 mysqli_query 执行。由于拼接发生在字符串上下文中，且 $current_user 来自 dvwaCurrentUser()（022.php:42）同样未参数化，攻击者可在口令字段中闭合单引号并追加任意 SQL 片段（如 ' , user='admin' -- 之类），从而改写任意用户口令或读取数据库内容。校验无效的原因：mysqli_real_escape_string 只转义引号等字符，但此处并未使用预处理语句，且拼接结构本身允许通过闭合引号改变语句语义；同时未对输入做长度/字符白名单限制。

影响：数据库任意写：可修改 users 表中任意用户（含 admin）的 password 字段，实现账户接管/越权登录；亦可借助 UPDATE 语句的报错或子查询进行数据外泄。属于高危数据完整性与机密性破坏。

CVE/CWE 论证：CWE-89（SQL 注入）。外部可达性：022.php 为可直接 HTTP 访问的 PHP 脚本，修改口令接口无需额外权限校验即可触达拼接点；利用链闭合：请求参数 → $pass_new（022.php:25）→ 字符串拼接（022.php:43）→ mysqli_query 执行（022.php:44），中间仅有一次不充分的转义，未使用参数化，故注入成立。

修复建议：改用预处理语句与参数绑定：$stmt = $mysqli->prepare('UPDATE users SET password = ? WHERE user = ?'); $stmt->bind_param('ss', $pass_hash, $current_user); $stmt->execute(); 同时对口令做长度与字符白名单校验，并在服务端使用 password_hash()/password_verify() 存储口令摘要，避免明文或弱摘要入库。

F-3 022.php 使用 MD5 存储口令（CWE-328 弱哈希）

medium weak_crypto / CWE-327 · 置信度 0.76 · candidate / rule_verified+llm

位置：022.php:38-39

022.php:38 先对 $pass_new 执行 mysqli_real_escape_string，随后在 022.php:39 调用 $pass_new = md5( $pass_new ); 将用户口令以无盐 MD5 摘要形式处理，并在 022.php:43-44 写入 users 表 password 字段。MD5 属于快速、无盐、已被证明存在实用碰撞的哈希算法，用于口令存储时无法抵抗离线暴力破解与彩虹表攻击。此处为配置/实现型弱点，不依赖 HTTP 污点链，根因是算法选择与缺少盐值/迭代。注意：该弱点类型应为 weak_hash（CWE-328），而非 weak_crypto（CWE-327，指 DES/ECB 等加密算法误用）。

影响：一旦数据库泄露（例如经由同文件 GEN-e38e01cf9ba5 的 SQL 注入或备份泄露），攻击者可用彩虹表或 GPU 暴力快速还原用户明文口令，进而横向登录其他系统；无盐设计使相同口令产生相同摘要，便于批量破解。

CVE/CWE 论证：CWE-328（使用弱哈希算法）。外部可达性：任何提交口令修改的请求都会触发 022.php:39 的 md5 计算并落库；无需认证即可观察该实现（结合同文件注入可进一步获取摘要）。利用链闭合：口令输入 → md5()（022.php:39）→ 写入 users.password（022.php:43-44）→ 数据库泄露后离线破解。

修复建议：改用 password_hash($pass_new, PASSWORD_DEFAULT)（bcrypt/Argon2）生成带盐、可调成本的摘要，校验时使用 password_verify()；迁移期可对旧 MD5 摘要在用户下次登录成功后透明重哈希。禁止在口令、令牌、签名等安全用途中使用 MD5/SHA-1。
