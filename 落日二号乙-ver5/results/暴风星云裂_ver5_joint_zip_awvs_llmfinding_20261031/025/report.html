F-1 025.php ping 功能通过 $_REQUEST['ip'] 黑名单绕过导致命令注入（shell_exec）

critical command_injection / CWE-78 · 置信度 0.93 · candidate / externally_corroborated

位置：025.php:3-34

脚本在收到 POST 参数 Submit 后，从 $_REQUEST['ip'] 读取攻击者可控输入 $target，仅用 str_replace 做黑名单替换（移除 ||、&、;、'| '、-、$、(、)、`），随后直接拼接进 shell_exec('ping -c 4 ' . $target)（Windows 分支为 'ping ' . $target）。黑名单存在多处缺陷：未过滤换行符 \n（shell 中作为命令分隔符）、未过滤 '|' 单字符（仅过滤了 '| ' 带空格形式）、未过滤 '>'、'<'、'#'、'\' 等；且 str_replace 为单次替换，可用 '||' 被替换为空后残留的构造或直接使用换行/单竖线绕过。攻击者可在 ping 目标后注入任意系统命令，以 Web 服务进程权限执行，导致服务器完全失陷。

影响：未认证远程攻击者可在服务器上以 Web 进程权限执行任意系统命令，读取/篡改文件、横向移动，导致服务器完全失陷。

CVE/CWE 论证：CWE-78 OS 命令注入。外部 HTTP 可达、无需认证、source（$_REQUEST['ip']）到 sink（shell_exec）链路在 025.php 内完整闭合，黑名单可被换行符/单竖线绕过，命令输出直接回显，利用确定性高。

修复建议：不要将用户输入拼接进 shell 命令；改用 escapeshellarg() 对目标做严格转义，或使用白名单校验（仅允许合法 IP/主机名正则，如 filter_var($target, FILTER_VALIDATE_IP)），并避免使用 shell_exec 执行外部命令。

F-2 025.php Windows 分支 OS 命令注入（CWE-78）

critical command_injection / CWE-78 · 置信度 0.83 · candidate / rule_verified+llm

位置：025.php:24-26

攻击者通过 HTTP 查询参数 `ip` 提供输入，该输入在 025.php:5 被读入变量 `target`，随后在 025.php:24 通过 `stristr(php_uname('s'),'Windows NT')` 判定为 Windows 平台后，于 025.php:26 直接拼接进 `shell_exec('ping ' . $target)`。代码片段中未见任何转义（escapeshellarg/escapeshellcmd）、白名单校验或参数化处理，因此 `target` 中的 shell 元字符（如 `&`、`|`、`;`）会被 shell 解释，形成命令注入。

影响：远程命令执行：攻击者可在 Web 服务器进程权限下执行任意系统命令，导致服务器被完全控制、数据泄露、横向移动。无需认证（取决于部署，但代码本身无鉴权逻辑）。

CVE/CWE 论证：CWE-78（OS 命令注入）。外部可达：`ip` 为 HTTP 查询参数，直接由远程用户控制；无需认证；利用链闭合：source（025.php:5 query `ip`）→ 变量 `target` → sink（025.php:26 `shell_exec`），中间无有效净化。

修复建议：避免将用户输入拼接进 shell 命令；使用参数化方式（如 `escapeshellarg($target)` 并对 IP 做严格格式校验，仅允许合法 IP 字符集），或改用不经过 shell 的 API（如 `proc_open` 传数组参数）。同时对 `ip` 做白名单/正则校验（如 `filter_var($target, FILTER_VALIDATE_IP)`）。
