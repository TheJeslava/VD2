位置：034.php:3-5

034.php 第 3 行从 $_GET['redirect'] 读取外部输入，第 4 行仅用 strpos($_GET['redirect'], "info.php") !== false 做子串包含判断，第 5 行直接把原始输入拼进 header("location: " . $_GET['redirect'])。由于校验只要求字符串中任意位置出现 info.php，攻击者可构造 https://evil.example/info.php 或 //evil.example/info.php 之类的外部 URL 通过校验，从而把用户重定向到攻击者控制的站点，用于钓鱼或 OAuth/SSO 场景下的令牌窃取。

影响：攻击者可构造可信域链接诱导用户跳转到钓鱼站点，或在 OAuth/SSO 回调场景中窃取授权码/令牌，造成账户接管风险。

CVE/CWE 论证：CWE-601 URL 重定向到不可信站点。外部无需认证即可通过 GET 参数触发，source→sink 链在 034.php:3-5 完整闭合，校验逻辑（strpos 子串匹配）可被外部 URL 直接绕过。

修复建议：不要直接使用用户输入作为 Location。改为白名单映射（如只允许固定相对路径 /info.php），或解析 URL 后校验 host 与 scheme 属于本站，并强制以 / 开头的站内相对路径。
