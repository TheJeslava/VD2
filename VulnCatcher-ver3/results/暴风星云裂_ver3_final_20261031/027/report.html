F-1 027.php ping 功能通过 $_REQUEST['ip'] 拼接 shell_exec 导致命令注入（黑名单仅过滤 && 与 ;）

critical command_injection / CWE-78 · 置信度 0.9 · candidate / llm_inferred

位置：027.php:3-27

027.php 在收到 POST 参数 Submit 后，直接把 $_REQUEST['ip'] 作为 $target，仅用 str_replace 删除 '&&' 和 ';' 两个子串，随后把 $target 拼进 shell_exec('ping -c 4 ' . $target)（Windows 分支为 'ping ' . $target）。黑名单不覆盖管道符 |、命令替换 $()、反引号 ``、换行符、后台符 &、以及 || 等，攻击者可在 ip 参数中注入任意系统命令，以 Web 服务进程权限执行，导致远程代码执行。

影响：未认证攻击者可在服务器上以 Web 进程权限执行任意系统命令，读取敏感文件、横向移动、植入后门，完全控制主机。

CVE/CWE 论证：CWE-78 OS 命令注入。外部可达（HTTP POST 参数 ip），无需认证，source→sink 链在 CODE PACK 内完整闭合（027.php:5 → 027.php:19/23），黑名单可被 | 与 $() 绕过，属典型 CVE 级命令注入。

修复建议：不要将用户输入拼接进 shell 命令。使用 escapeshellarg() 对 $target 转义，或改用白名单校验（仅允许合法 IP/主机名正则），并优先使用参数化方式（如 proc_open 传数组参数）执行 ping。

F-2 027.php Windows 分支 ping 命令拼接导致 OS 命令注入（CWE-78）

critical command_injection / CWE-78 · 置信度 0.78 · candidate / rule_verified+llm

位置：027.php:17-19

攻击者通过 HTTP 查询参数 `ip` 提供输入（027.php:5 读取到 `$target`），该值未经任何转义或白名单校验，在 Windows 分支（`stristr(php_uname('s'),'Windows NT')` 为真，027.php:17）被直接字符串拼接到 `shell_exec('ping ' . $target)`（027.php:19）。由于拼接发生在 shell 解释之前，`$target` 中的 `&`、`|`、`;`（Windows cmd 下 `&`/`|`）等元字符会被 shell 解析为命令分隔符，从而执行攻击者附加的任意命令。代码中未见 escapeshellarg/escapeshellcmd、白名单或参数化调用，校验完全缺失。

影响：远程命令执行（RCE）：攻击者可在 Web 服务进程权限下执行任意系统命令，读取/篡改应用与系统文件、窃取数据库凭据、横向移动，完全失陷主机。无需认证即可通过 GET 请求触发。

CVE/CWE 论证：CWE-78（OS Command Injection）。外部可达性：入口为公开 HTTP 查询参数 `ip`（027.php:5），无需认证；利用链闭合：`ip` → `$target` → 字符串拼接 → `shell_exec`（027.php:19），中间无净化，shell 元字符可注入。属于典型的不可信输入直接进入命令解释器。

修复建议：不要用 shell 拼接执行 ping。改用参数数组形式并禁用 shell，例如 PHP 中用 `proc_open`/`exec` 传数组参数，或直接使用 `filter_var($target, FILTER_VALIDATE_IP)` 严格校验为合法 IP 后再以参数化方式调用；同时对输入做白名单（仅允许 IPv4/IPv6 字面量），拒绝含 shell 元字符的输入，并以最小权限账户运行 Web 服务。

F-3 027.php *nix 分支 ping 命令拼接导致 OS 命令注入（CWE-78）

critical command_injection / CWE-78 · 置信度 0.78 · candidate / rule_verified+llm

位置：027.php:21-23

攻击者通过 HTTP 查询参数 `ip` 提供输入（027.php:5 读取到 `$target`），在非 Windows 分支（027.php:21 的 else）被直接拼接到 `shell_exec('ping -c 4 ' . $target)`（027.php:23）。`$target` 未经 escapeshellarg/escapeshellcmd 或白名单校验，`;`、`|`、`&`、`$()`、反引号等 shell 元字符会被 /bin/sh 解释，导致执行攻击者附加的任意命令。
