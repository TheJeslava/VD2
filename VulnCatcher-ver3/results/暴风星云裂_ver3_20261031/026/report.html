F-1 026.php ping 功能通过 $_REQUEST['ip'] 造成命令注入（shell_exec）

critical command_injection / CWE-78 · 置信度 0.9 · candidate / llm_inferred

位置：026.php:3-18

脚本在收到 POST 参数 Submit 后，直接把 $_REQUEST['ip'] 拼接到 shell_exec('ping -c 4 ' . $target)（Windows 分支为 'ping ' . $target）中执行，未做任何白名单、转义（escapeshellarg/escapeshellcmd）或输入校验。攻击者可通过 ip 参数注入 shell 元字符（; | & $() 反引号 换行等），在服务器上以 Web 进程权限执行任意命令，形成完整 RCE。

影响：未认证远程攻击者可在 Web 服务器上以 PHP 进程权限执行任意系统命令，完全控制主机、读取敏感文件、横向移动。

CVE/CWE 论证：CWE-78 OS Command Injection。外部 HTTP 参数 ip 经 $_REQUEST 直达 shell_exec，无认证、无过滤，source→sink 链在 CODE PACK 内完整闭合，属典型可申报 CVE 的 RCE。

修复建议：不要将用户输入拼入 shell 命令；改用 escapeshellarg($target) 并对 ip 做严格 IP 格式校验（filter_var FILTER_VALIDATE_IP），或使用参数数组方式调用（如 proc_open 传数组）避免 shell 解析。

F-2 026.php Windows 分支 OS 命令注入（CWE-78）

critical command_injection / CWE-78 · 置信度 0.78 · candidate / rule_verified+llm

位置：026.php:8-10

攻击者通过 HTTP 查询参数 `ip` 提供输入（026.php:5 读取该参数并赋给 `$target`）。程序在 026.php:8 用 `stristr(php_uname('s'),'Windows NT')` 判断运行平台，命中 Windows 分支后，在 026.php:10 执行 `$cmd = shell_exec( 'ping ' . $target );`。`$target` 未经任何转义、白名单校验或参数化处理，被直接拼接到 shell 命令字符串中，因此 `&`、`|`、`&&`、`;` 等 shell 元字符会被解释为命令分隔符，导致任意命令执行。该分支的校验完全缺失，属于典型的字符串拼接式命令注入。

影响：远程未认证攻击者可在 Windows 主机上以 Web 服务进程权限执行任意系统命令，导致服务器完全失陷、数据泄露、横向移动与持久化。

CVE/CWE 论证：CWE-78（OS 命令注入）。外部可达性：注入点来自 HTTP query 参数 `ip`，无需认证即可触发；利用链闭合：`ip` → `$target`（026.php:5）→ `shell_exec('ping ' . $target)`（026.php:10），中间无净化函数，攻击者可控拼接内容直接进入 shell 解释器。

修复建议：不要用字符串拼接构造 shell 命令。改用参数数组形式并避免 shell 解释，例如在 PHP 中使用 `escapeshellarg($target)` 对参数做严格转义，或使用 `proc_open` 传入参数数组；同时对 `$target` 做严格白名单校验（仅允许合法 IP/域名正则，如 `^[a-zA-Z0-9.\-]+$`），并遵循最小权限运行 Web 服务。
