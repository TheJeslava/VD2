F-1 036.php redirect 参数未校验导致的开放重定向（协议相对 URL 绕过）

medium open_redirect / CWE-601 · 置信度 0.82 · candidate / llm_inferred

位置：036.php:3-13

036.php 第 3 行从 $_GET['redirect'] 读取重定向目标，第 4 行仅用正则 /http:\/\/|https:\/\//i 拦截以 http:// 或 https:// 开头的绝对 URL，第 11 行直接执行 header("location: " . $_GET['redirect'])。该黑名单只匹配带 scheme 的绝对 URL，未拦截以 // 开头的协议相对 URL（如 //evil.example），也未拦截反斜杠变体（如 /\evil.example，部分浏览器会规范化为 //evil.example），因此攻击者可构造 //attacker.tld 使 Location 头指向外部域，实现开放重定向。该脚本无任何认证，直接 HTTP 访问即可触发。

影响：攻击者可借助受信任域名的链接将用户重定向到钓鱼/恶意站点，用于凭据窃取或 OAuth/SSO 流程劫持；由于脚本无认证，任何访问者均可被诱导。

CVE/CWE 论证：CWE-601 URL Redirection to Untrusted Site（Open Redirect）。外部可达、无需认证、source→sink 链在 036.php:3-11 完整闭合，黑名单可被协议相对 URL 绕过。

修复建议：不要使用黑名单。改为白名单校验：解析目标后仅允许相对路径（拒绝以 // 或 /\ 开头），或维护允许的 host 列表并比对 parse_url 的 host；也可仅接受站内相对路径并强制以单个 / 开头且不含 //。
