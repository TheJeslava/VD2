F-1 027.php ping 功能通过 ip 参数导致命令注入（shell_exec 黑名单可绕过）

critical command_injection / CWE-78 · 置信度 0.9 · candidate / llm_inferred

位置：027.php:3-27

027.php 在收到 POST 参数 Submit 后，从 $_REQUEST['ip'] 读取用户输入，仅用 str_replace 删除 '&&' 与 ';' 两个字符串作为黑名单，随后直接拼接进 shell_exec('ping -c 4 ' . $target)（Windows 分支为 shell_exec('ping ' . $target)）。黑名单只过滤 '&&' 和 ';'，未过滤管道符 '|'、命令替换 '$(...)'、反引号、换行、'||'、'&' 等 shell 元字符，也未使用 escapeshellarg/escapeshellcmd，因此攻击者可注入任意系统命令并以 Web 进程权限执行，形成 RCE。

影响：远程未授权攻击者可在 Web 服务器上以 Web 进程权限执行任意系统命令，读取敏感文件、横向移动、植入后门，完全控制主机。

CVE/CWE 论证：CWE-78 OS 命令注入。外部 HTTP 可达，无需认证，source（$_REQUEST['ip']）到 sink（shell_exec）链路在 027.php 内完整闭合，黑名单可被常见 shell 元字符绕过，属典型可申报 CVE 的 RCE。

修复建议：不要将用户输入拼接进 shell 命令；改用 escapeshellarg($target) 对参数整体转义，或使用白名单校验 IP 格式（filter_var($target, FILTER_VALIDATE_IP)），并避免使用 shell_exec 执行外部命令。

F-2 027.php Windows 分支 ping 命令拼接导致 OS 命令注入（CWE-78）

critical command_injection / CWE-78 · 置信度 0.78 · candidate / rule_verified+llm

位置：027.php:17-19

攻击者通过 HTTP query 参数 `ip` 提供输入，027.php:5 将其读入 `$target`；027.php:17 用 `stristr(php_uname('s'),'Windows NT')` 判断运行平台，命中 Windows 分支后，027.php:19 执行 `$cmd = shell_exec( 'ping ' . $target );`，把外部输入直接字符串拼接进 shell 命令。代码中未见 escapeshellarg/escapeshellcmd、白名单校验或 IP 格式规范化，因此 `$target` 中的 `&`、`|`、`;`、`&&` 等 shell 元字符会被解释为命令分隔符，校验完全失效，污点直达 shell_exec 汇点。

影响：远程未认证攻击者可在 Web 服务器进程权限下执行任意系统命令（Windows 分支），导致服务器被完全控制、读取/篡改任意文件、横向移动；属于 RCE 级影响。

CVE/CWE 论证：CWE-78（OS Command Injection）。外部可达性：入口为 HTTP query 参数 `ip`（027.php:5），无需认证；利用链闭合：`ip` → `$target` → 字符串拼接 → `shell_exec`（027.php:19），中间无有效净化，攻击者可控命令分隔符即可追加任意命令。

修复建议：不要用 shell 拼接执行 ping：改用参数数组形式（如 proc_open/exec 传数组）或直接使用语言内置的 ICMP/网络库；若必须调用外部程序，对 `$target` 做严格白名单校验（仅允许合法 IPv4/IPv6 字符集与格式，用 filter_var FILTER_VALIDATE_IP），并配合 escapeshellarg 作为纵深防御；以最小权限账户运行 Web 服务。

F-3 027.php *nix 分支 ping -c 4 命令拼接导致 OS 命令注入（CWE-78）

critical command_injection / CWE-78 · 置信度 0.78 · candidate / rule_verified+llm

位置：027.php:21-23

攻击者通过 HTTP query 参数 `ip` 提供输入，027.php:5 将其读入 `$target`；当 027.php:17 的平台判断不命中 Windows 时进入 else 分支，027.php:23 执行 `$cmd = shell_exec( 'ping -c 4 ' . $target );`，外部输入被直接拼接进 shell 命令。代码中未见 escapeshellarg/escapeshellcmd、白名单或 IP 格式校验，`;`、`|`、`&&`、`$()`、反引号等 shell 元字符可突破 ping 参数边界执行任意命令，校验无效，污点直达 shell_exec 汇点。

影响：远程未认证攻击者在 *nix 部署下可以 Web 服务进程权限执行任意系统命令，实现 RCE、读取敏感文件、建立持久化或横向渗透。

CVE/CWE 论证：CWE-78（OS Command Injection）。外部可达性：HTTP query 参数 `ip`（027.php:5）无需认证即可控制；利用链闭合：`ip` → `$target` → 拼接 → `shell_exec`（027.php:23），无有效净化，命令分隔符可控。

修复建议：避免 shell 字符串拼接，改用参数数组方式调用外部程序或使用内置网络库；对 `$target` 使用 filter_var(..., FILTER_VALIDATE_IP) 严格校验并拒绝非法字符，必要时叠加 escapeshellarg；以最小权限运行服务并限制出站能力。
