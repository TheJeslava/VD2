F-1 026.php ping 功能通过 $_REQUEST['ip'] 拼接 shell_exec 导致未授权远程命令执行

critical command_injection / CWE-78 · 置信度 0.9 · candidate / llm_inferred

位置：026.php:5-14

026.php 在收到 POST 参数 Submit 后，直接从 $_REQUEST['ip'] 读取用户输入（第 5 行），未做任何白名单、转义或参数化处理，随后在第 10 行（Windows 分支）或第 14 行（*nix 分支）将其字符串拼接到 shell_exec('ping ... ' . $target) 中执行。攻击者可在 ip 参数中注入 shell 元字符（如 ; | & ` $() 换行）执行任意系统命令。由于 $_REQUEST 同时接受 GET/POST/Cookie，且脚本无任何认证或 CSRF 防护，任何能访问该脚本的人均可直接触发，形成未授权 RCE。

影响：未授权攻击者可在服务器上以 Web 服务进程权限执行任意系统命令，读取敏感文件、横向移动、植入后门，完全控制主机。

CVE/CWE 论证：CWE-78 OS 命令注入。外部可达（无认证、无 CSRF token），source（$_REQUEST['ip']）到 sink（shell_exec）链路完整且无任何过滤，属于典型 DVWA 式命令注入，可稳定复现，符合 CVE/赏金平台接收标准。

修复建议：不要将用户输入拼接进 shell 命令；使用 escapeshellarg() 对 $target 转义，或改用白名单校验 IP 格式（filter_var($target, FILTER_VALIDATE_IP)），并优先使用参数化方式（如 proc_open 传数组参数）执行 ping。

F-2 026.php Windows 分支 ping 命令拼接导致 OS 命令注入（CWE-78）

critical command_injection / CWE-78 · 置信度 0.78 · candidate / rule_verified+llm

位置：026.php:8-10

攻击者通过 HTTP 查询参数 `ip` 提供输入，该参数在 026.php:5 被读入变量 `target`，随后在 026.php:8 通过 `stristr(php_uname('s'), 'Windows NT')` 判断运行平台；当目标为 Windows 时进入 026.php:10，执行 `$cmd = shell_exec( 'ping ' . $target );`。代码仅做字符串拼接，未对 `target` 做任何白名单校验、转义（如 escapeshellarg）或参数化，因此 `target` 中的 shell 元字符（如 `&`、`|`、`;`）会被 shell 解释为命令分隔符，导致任意命令执行。该分支的触发条件为服务器运行于 Windows NT 平台。

影响：远程未认证攻击者可在 Web 服务器进程权限下执行任意操作系统命令，导致服务器完全失陷、敏感数据泄露、横向移动及持久化。

CVE/CWE 论证：CWE-78（OS 命令注入）。外部可达性：注入点为 HTTP 查询参数 `ip`，无需认证即可访问；利用链闭合：`ip` → `target`（026.php:5）→ 字符串拼接进入 `shell_exec`（026.php:10），中间无有效净化。该分支仅在 Windows 平台生效，属平台条件性可达。

修复建议：避免将外部输入拼接进 shell 命令；改用参数数组形式调用（如 proc_open/exec 传入参数数组），或对 `target` 使用严格白名单（仅允许合法 IP/主机名正则），并在必须拼接时使用 escapeshellarg/escapeshellcmd 转义；同时以最小权限运行 Web 进程。
