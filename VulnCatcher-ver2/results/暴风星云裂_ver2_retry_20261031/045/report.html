F-1 045.php 不安全文件上传导致任意文件落盘（CWE-434）

critical file_upload / CWE-434 · 置信度 0.73 · candidate / rule_verified+llm

位置：045.php:16-18

攻击者通过 HTTP 多部分表单上传文件，文件内容进入 PHP 超全局数组 $_FILES['uploaded']，其中 $_FILES['uploaded']['tmp_name'] 为临时文件路径、$_FILES['uploaded']['name'] 为客户端可控的原始文件名。代码在 045.php:18 直接调用 move_uploaded_file($_FILES['uploaded']['tmp_name'], $target_path) 将上传文件移动到目标路径 $target_path。从给出的片段看，第 16-18 行之间不存在扩展名白名单、MIME 校验、文件内容检测或文件名规范化逻辑，$target_path 的构造（是否拼接客户端文件名、是否限制在固定目录）在片段中未体现，因此无法证明存在有效净化。校验缺失使攻击者可控制落盘文件的名称/扩展名，从而把可执行脚本写入 Web 可访问目录。

影响：任意文件写入 Web 根目录：若 $target_path 位于可被 Web 服务器解析的目录且允许 .php/.phtml 等扩展名，攻击者可上传 WebShell 实现远程代码执行（RCE）；即使不可执行，也可覆盖/投放任意文件、造成存储型内容注入或磁盘占用。属于高危（critical）级别。

CVE/CWE 论证：CWE-434 Unrestricted Upload of File with Dangerous Type。外部可达性：上传入口为 HTTP 表单字段 uploaded，无需认证即可访问 045.php；利用链闭合：$_FILES['uploaded']['tmp_name'] → move_uploaded_file() → $target_path 落盘，中间无扩展名/类型白名单，攻击者可直接提交恶意文件完成利用。注意：$target_path 的具体构造在给定片段（045.php:16-18）中未展示，若其被固定为安全目录或强制重命名，实际可利用性会下降，此点属证据不足。

修复建议：1) 使用扩展名白名单（如仅 jpg/png/pdf）并基于服务端检测的真实 MIME/魔数校验，而非客户端 Content-Type；2) 忽略客户端文件名，由服务端生成随机文件名（如 UUID）并强制追加白名单扩展名；3) 将上传目录置于 Web 根之外，或配置 Web 服务器禁止该目录执行脚本（如 php_flag engine off / 禁止 .php 解析）；4) 限制文件大小与数量，校验路径规范化后仍位于预期目录内（防目录穿越）；5) 上传后文件以最小权限存储，必要时做病毒/内容扫描。

F-2 DVWA 上传端点 045.php 仅校验客户端可控的 MIME 类型，可上传任意 PHP 脚本导致远程代码执行

high file_upload / CWE-434 · 置信度 0.9 · candidate / llm_inferred

位置：045.php:3-26

045.php 处理 multipart 上传时，用 $_FILES['uploaded']['type']（完全由客户端 multipart 请求的 Content-Type 决定）判断是否为 image/jpeg 或 image/png，并仅限制 size<100000，随后直接 move_uploaded_file 到 DVWA_WEB_PAGE_TO_ROOT."hackable/uploads/" 目录，文件名取 basename($_FILES['uploaded']['name'])。服务端未做任何内容嗅探（getimagesize/finfo）、未做扩展名白名单、未重命名、未禁止脚本扩展。攻击者把 Content-Type 伪造成 image/jpeg 并上传 shell.php，即可在 Web 可访问的 uploads 目录落地可执行 PHP，形成 RCE。

影响：任意文件上传导致在服务器上执行任意 PHP 代码，完全控制 Web 应用与主机（RCE）。

CVE/CWE 论证：CWE-434 无限制文件上传 / CWE-646 依赖不可信文件元数据。外部无需认证即可通过 HTTP 触发，链完整闭合（source $_FILES → 弱校验 → move_uploaded_file → Web 可执行）。

修复建议：使用 getimagesize()/finfo 做服务端内容检测；对扩展名做白名单并强制重命名；将上传目录置于 Web 根之外或禁用脚本执行；限制目录权限。
