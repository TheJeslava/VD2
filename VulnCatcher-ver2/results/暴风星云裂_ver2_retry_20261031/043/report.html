F-1 043.php 不安全文件上传导致任意文件写入（CWE-434）

critical file_upload / CWE-434 · 置信度 0.78 · candidate / rule_verified+llm

位置：043.php:18-20

攻击者通过 HTTP 上传请求的 `uploaded` 文件字段（043.php:12 读取上传文件，临时路径进入 `$uploaded_tmp`）提交任意内容与任意文件名的文件。代码在 043.php:20 直接调用 `move_uploaded_file( $uploaded_tmp, $target_path )` 将临时文件移动到 `$target_path`，在给出的片段（043.php:18-20）中未见对扩展名、MIME 类型、文件内容或目标路径的白名单校验，也未见对 `$target_path` 的规范化与目录限制，因此校验无效。最终危险操作是 `move_uploaded_file` 把攻击者可控内容写入 Web 可访问目录。

影响：攻击者可上传 .php 等可执行脚本到 Web 根目录下，随后通过 HTTP 请求触发执行，形成远程代码执行（RCE）；即使目标目录禁止脚本执行，也可造成任意文件写入/覆盖、磁盘占用与恶意内容托管（钓鱼、恶意下载）。无需认证即可利用（取决于部署是否在 043.php 前加访问控制，代码片段本身未见认证逻辑）。

CVE/CWE 论证：CWE-434（Unrestricted Upload of File with Dangerous Type）。外部可达性：入口为 HTTP multipart 上传，`uploaded` 字段由客户端完全控制；无需认证（片段内无鉴权代码）；利用链闭合：`uploaded` → `$uploaded_tmp`（043.php:12）→ `move_uploaded_file($uploaded_tmp, $target_path)`（043.php:20），中间无扩展名/MIME/内容白名单与路径规范化，攻击者可直接落盘可执行脚本。证据等级为源码推断（llm_inferred），未做动态验证。

修复建议：1) 使用扩展名白名单（如仅 jpg/png/gif/pdf）并同时校验服务端探测的 MIME 与文件魔数，不信任客户端 Content-Type；2) 上传文件名由服务端随机生成（UUID），不使用客户端文件名，禁止路径分隔符与 `..`；3) 将上传目录置于 Web 根之外，或配置该目录禁止脚本执行（如 Nginx `location ~ \.php$ { deny all; }`）；4) 对 `$target_path` 做 `realpath` 规范化并校验其前缀必须落在允许的上传目录内；5) 上传目录以最小权限运行，文件权限设为 0644 且属主非 Web 进程；6) 在 043.php 前增加认证与 CSRF 防护、限制上传大小与频率。

F-2 DVWA 文件上传端点（043.php）仅校验扩展名与 getimagesize，可上传含 PHP 代码的图片并写入 web 可访问目录

high file_upload / CWE-434 · 置信度 0.77 · candidate / llm_inferred

位置：043.php:3-27

043.php 在收到 POST 参数 Upload 时，直接取 $_FILES['uploaded']['name'] 经 basename() 拼接到 DVWA_WEB_PAGE_TO_ROOT."hackable/uploads/" 后作为 move_uploaded_file 的目标路径。校验仅有三点：扩展名（strtolower 后必须为 jpg/jpeg/png）、大小 <100000 字节、getimagesize() 返回真。getimagesize 只检查文件头是否为合法图片，不检查文件其余内容，因此攻击者可构造「合法 PNG/JPG 头 + 尾部 PHP 代码」的 polyglot 文件通过校验，并被写入 web 根下 hackable/uploads/ 目录。若目标服务器对该目录下的 .php 解析（DVWA 默认部署常见），即可通过访问上传文件执行任意 PHP 代码，形成 RCE。

影响：可上传任意内容文件至 web 可访问目录；在常见 DVWA 部署下可进一步执行任意 PHP 代码，导致服务器被控。

CVE/CWE 论证：CWE-434 无限制文件上传。外部可直接通过 HTTP multipart 触发，无需高权限；链闭合至文件落盘，RCE 取决于 uploads 目录解析配置（运行时条件）。

修复建议：使用白名单校验扩展名并重命名文件（随机名 + 固定安全扩展名）；将上传目录移出 web 根或禁止脚本执行；对图片做二次编码（如 GD 重绘）剥离尾部代码；校验 MIME 与文件内容一致性。
