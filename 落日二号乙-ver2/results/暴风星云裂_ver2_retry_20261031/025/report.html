F-1 025.php ping 工具页 ip 参数黑名单过滤可绕过导致 shell_exec 命令注入

critical command_injection / CWE-78 · 置信度 0.9 · candidate / llm_inferred

位置：025.php:5-30

025.php 在收到 POST 参数 Submit 后，从 $_REQUEST['ip'] 读取用户输入（第5行），仅用 str_replace 做黑名单替换（第8-21行），随后直接拼接进 shell_exec('ping -c 4 ' . $target)（第30行，Windows 分支为第26行）。黑名单只过滤了 ||、&、;、'| '、-、$、(、)、` 等字符，未过滤换行符 \n、空格、重定向符 >、<、以及未被列入的管道符 '|'（注意黑名单里是 '| ' 带空格，单独的 '|' 不在其中）。攻击者可用换行符或空格+重定向/管道构造任意命令执行，属于典型的 OS 命令注入（CWE-78）。

影响：未授权远程攻击者可在服务器上以 Web 进程权限执行任意系统命令，读取敏感文件、写入 webshell、横向移动，完全控制主机。

CVE/CWE 论证：CWE-78 OS 命令注入。外部可达（HTTP POST），无需认证，source→sink 链完整闭合，黑名单可被换行符/重定向符绕过，属高危可利用漏洞。

修复建议：不要将用户输入拼接进 shell 命令；使用 escapeshellarg() 对参数转义，或改用白名单校验 IP 格式（filter_var($ip, FILTER_VALIDATE_IP)），并避免使用 shell_exec 执行外部命令。

F-2 025.php Windows 分支 ping 命令拼接导致 OS 命令注入（CWE-78）

critical command_injection / CWE-78 · 置信度 0.83 · candidate / rule_verified+llm

位置：025.php:24-26

攻击者通过 HTTP 查询参数 `ip` 提供输入（025.php:5 读取到 `$target`），该值未经任何转义或白名单校验，在 Windows 分支（`stristr(php_uname('s'),'Windows NT')` 为真，025.php:24）被直接字符串拼接到 `shell_exec('ping ' . $target)`（025.php:26）。由于拼接发生在 shell 解释之前，`$target` 中的 `&`、`|`、`&&`、`;`（Windows cmd 下 `&`/`|`/`&&`）等元字符会被 shell 解释为命令分隔符，从而执行攻击者附加的任意命令。代码中不存在 escapeshellarg/escapeshellcmd、白名单或输入格式校验，因此校验完全缺失。

影响：远程未认证攻击者可在 Web 服务器进程权限下执行任意系统命令，导致服务器完全失陷（RCE）、敏感文件读取、内网横向移动与持久化。

CVE/CWE 论证：CWE-78（OS 命令注入）。外部可达性：入口为 HTTP query 参数 `ip`，无需认证；利用链闭合：`ip` → `$target`（025.php:5）→ 字符串拼接 → `shell_exec`（025.php:26），中间无净化，攻击者可用 `127.0.0.1 & whoami` 之类载荷闭合注入。该分支仅在 Windows 主机触发，属环境相关可达性，但一旦命中即完整可利用。

修复建议：不要通过 shell 拼接执行 ping：使用 `proc_open`/`exec` 的数组形式（如 `exec('ping', ['-n','4',$target])`）避免 shell 解析；同时对 `$target` 做严格白名单校验（仅允许 IPv4/IPv6 字面量，使用 `filter_var($target, FILTER_VALIDATE_IP)`），拒绝含空白与 shell 元字符的输入；以最小权限运行 Web 进程。
