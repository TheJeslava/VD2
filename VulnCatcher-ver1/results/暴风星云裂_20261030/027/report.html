F-1 027.php ping 功能 $_REQUEST['ip'] 黑名单过滤可绕过导致 shell_exec 命令注入

critical command_injection / CWE-78 · 置信度 0.9 · candidate / llm_inferred

位置：027.php:3-27

027.php 在收到 POST 参数 Submit 后，从 $_REQUEST['ip'] 读取目标地址（第5行），仅用 str_replace 删除 '&&' 与 ';' 两个子串（第8-14行）作为黑名单，随后直接拼接进 shell_exec('ping -c 4 ' . $target)（第23行，Windows 分支为第19行）。黑名单只覆盖两个分隔符，未过滤管道符 |、命令替换 $()、反引号 ``、换行符、& 单符号、|| 等，攻击者可在 ip 参数中注入任意命令并以 Web 进程权限执行，构成完整的远程命令执行链。

影响：未认证攻击者可在 Web 服务器上以 Web 进程权限执行任意系统命令，读取/篡改文件、横向移动、建立持久化，导致服务器完全失陷。

CVE/CWE 论证：CWE-78（OS 命令注入）。外部可达：$_REQUEST['ip'] 直接来自 HTTP 请求；无需认证；黑名单仅过滤 '&&' 与 ';'，管道符/命令替换/反引号/换行均可绕过；source→sink 链在 027.php 内完整闭合，无中间校验层。

修复建议：不要将用户输入拼接进 shell 命令。使用 escapeshellarg($target) 对参数转义，或改用白名单校验（如 filter_var($target, FILTER_VALIDATE_IP) 仅允许合法 IP），并避免使用 shell_exec 执行外部命令。
