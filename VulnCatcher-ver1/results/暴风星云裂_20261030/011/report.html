F-1 011.php 登录接口 username 参数 SQL 注入（可绕过认证）

critical sql_injection / CWE-89 · 置信度 0.9 · candidate / llm_inferred

位置：011.php:5-13

011.php 第 3 行通过 $_GET['Login'] 触发登录逻辑，第 5 行直接读取 $_GET['username'] 到 $user，未做任何转义/参数化；第 12 行将 $user 直接拼接进 SQL 语句 "SELECT * FROM `users` WHERE user = '$user' AND password = '$pass';"，第 13 行 mysqli_query 执行。攻击者可在 username 中注入闭合单引号并构造恒真条件，绕过密码校验以任意已知用户（如 admin）身份登录，或通过报错注入/联合查询读取 users 表全部数据（含口令散列）。

影响：未授权攻击者可绕过登录认证进入受保护区域，并可读取 users 表全部记录（用户名与 MD5 口令散列），为进一步爆破/横向移动提供条件。

CVE/CWE 论证：CWE-89。外部 GET 参数 username 未经参数化直接拼接进 SQL 并由 mysqli_query 执行，链路在单个文件内闭合，无需认证即可触发。

修复建议：使用 mysqli 预处理语句（prepare + bind_param）或 PDO 参数化查询；对输入做类型/白名单校验；关闭 die(mysqli_error) 的详细错误回显。
