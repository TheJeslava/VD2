high file_upload / CWE-434 · 置信度 0.88 · candidate / llm_inferred

位置：044.php:3-16

044.php 在收到 POST 参数 Upload 后，直接把 $_FILES['uploaded']['name'] 经 basename() 处理后拼接到 DVWA_WEB_PAGE_TO_ROOT . "hackable/uploads/" 目录，并调用 move_uploaded_file() 落盘。代码未做任何扩展名白名单、MIME 校验、getimagesize 图像校验、文件大小限制或随机重命名，攻击者可上传 .php 文件到 Web 可访问的 hackable/uploads/ 目录，随后直接请求该文件即可执行任意 PHP 代码，形成远程代码执行。

影响：攻击者可在 Web 根目录写入任意 PHP 文件并执行，获得服务器代码执行权限，进而读取配置/数据库凭据、横向移动、植入持久后门。

CVE/CWE 论证：CWE-434 Unrestricted Upload of File with Dangerous Type。外部 HTTP 可达，无需高权限，source（上传文件名）→ sink（move_uploaded_file）链路在 044.php 内完整闭合，无任何白名单/校验节点，属典型可申报 CVE 的任意文件上传 RCE。

修复建议：1) 使用扩展名白名单（仅 jpg/png/gif 等）并校验真实 MIME 与 getimagesize；2) 上传文件随机重命名并去除原始扩展名；3) 上传目录置于 Web 根之外或禁用 PHP 解析（如 nginx location 拒绝 .php 执行）；4) 限制文件大小；5) 上传接口增加认证与 CSRF 校验。
