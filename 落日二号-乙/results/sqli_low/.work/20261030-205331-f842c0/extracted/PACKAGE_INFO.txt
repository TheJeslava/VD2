DVWA vulnerability sample package

This folder preserves the DVWA-relative paths for the selected vulnerability module and its shared runtime context.
The module's index, help, auxiliary endpoints, data, and non-level helper files are included. Only the selected
source/<level>.php implementation is retained; sibling security-level implementations are excluded.

Shared files included: config templates, database setup files, DVWA page/database framework, external libraries,
hackable fixture data, and root setup/auth/security context files. The API module's composer metadata is included;
its vendor directory is absent from the source checkout.

Original source: DVWA
Sample: sqli_low
Selected source: vulnerabilities/sqli/source/low.php
