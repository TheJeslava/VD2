F-1 027.php ping 功能通过 $_REQUEST['ip'] 拼接 shell_exec 导致命令注入

critical command_injection / CWE-78 · 置信度 0.9 · candidate / llm_inferred

位置：027.php:3-24

脚本在收到 POST 参数 Submit 后，从 $_REQUEST['ip'] 读取用户输入 $target，仅用 str_replace 删除 '&&' 与 ';' 两个黑名单字符串，随后直接拼接进 shell_exec('ping -c 4 ' . $target)（Windows 分支为 'ping ' . $target）。黑名单不覆盖管道符 |、命令替换 $()、反引号、换行符 %0a、后台符 &、以及 || 等，攻击者可在 ip 参数中注入任意系统命令，以 Web 服务进程权限执行，导致远程代码执行。

影响：未认证攻击者可在服务器上以 Web 服务进程权限执行任意系统命令，读取敏感文件、横向移动、植入后门，完全控制主机。

CVE/CWE 论证：CWE-78 OS 命令注入。外部 HTTP 可达、无需认证、source（$_REQUEST['ip']）到 sink（shell_exec）链路在 CODE PACK 内完整闭合，黑名单可被常见 shell 元字符绕过，属典型 CVE 级 RCE。

修复建议：不要将用户输入拼接进 shell 命令；改用 escapeshellarg() 对目标做严格转义，或使用白名单校验 IP 格式（filter_var($target, FILTER_VALIDATE_IP)），并避免使用 shell_exec 执行外部命令。

F-2 027.php Windows 分支 ping 命令拼接导致 OS 命令注入（CWE-78）

critical command_injection / CWE-78 · 置信度 0.83 · candidate / rule_verified+llm

位置：027.php:17-19

攻击者通过 HTTP 查询参数 `ip` 提供输入（027.php:5 读取该参数并赋给 `$target`）。当 `php_uname('s')` 返回包含 `Windows NT` 的字符串时，代码进入 Windows 分支（027.php:17-18），在 027.php:19 执行 `$cmd = shell_exec( 'ping ' . $target );`，把未净化的 `$target` 直接拼接到 shell 命令字符串中。代码未对 `$target` 做任何白名单校验、转义（如 escapeshellarg/escapeshellcmd）或参数化处理，因此 `$target` 中的 shell 元字符（如 `&`、`|`、`;`、`&&`）会被 shell 解释，从而执行攻击者附加的命令。

影响：远程命令执行（RCE）：攻击者可在 Web 服务器进程权限下执行任意系统命令，导致服务器被完全控制、敏感数据泄露、横向移动及持久化。无需认证即可通过单个 HTTP 请求触发。

CVE/CWE 论证：CWE-78（OS 命令注入）。外部可达性：注入点来自 HTTP 查询参数 `ip`，任何能访问该脚本的攻击者均可控制。无需认证：脚本未包含任何认证/授权检查。利用链闭合：`ip` 参数（027.php:5）→ `$target` → 字符串拼接进 `shell_exec('ping ' . $target)`（027.php:19），中间无有效净化，污点直达危险汇点。

修复建议：不要将外部输入拼接进 shell 命令。优先使用参数数组形式并避免 shell 解释（如 PHP 的 `proc_open` 配合参数数组，或直接调用系统 API）。若必须调用 ping，应对 `$target` 做严格白名单校验（仅允许合法 IP/主机名正则，如 `^[a-zA-Z0-9.-]+$`），并使用 `escapeshellarg($target)` 转义；同时以最小权限运行 Web 进程，禁用不必要的危险函数。
