F-1 026.php ping 功能通过 $_REQUEST['ip'] 造成命令注入（shell_exec）

critical command_injection / CWE-78 · 置信度 0.9 · candidate / llm_inferred

位置：026.php:3-18

026.php 在收到 POST 参数 Submit 后，直接把 $_REQUEST['ip'] 拼接到 shell_exec('ping -c 4 ' . $target)（*nix）或 shell_exec('ping ' . $target)（Windows）中执行，未做任何白名单、转义（escapeshellarg/escapeshellcmd）或类型校验。攻击者可通过 ip 参数注入 shell 元字符（;、|、&&、$()、反引号）在服务器上执行任意命令，且命令输出通过 $cmd 回显到页面 <pre> 中，形成可回显的 RCE。由于使用 $_REQUEST，GET/POST/Cookie 均可投递。

影响：未认证远程攻击者可在 Web 服务器进程权限下执行任意系统命令，完全控制主机，读取/篡改数据、横向移动。

CVE/CWE 论证：CWE-78 OS 命令注入。外部可达（HTTP 参数 ip），无需认证，source→sink 链在 026.php:5→10/14 完整闭合，命令输出可回显，属典型 CVE 级 RCE。

修复建议：不要将用户输入拼入 shell 命令；使用 escapeshellarg($target) 包裹参数，或改用白名单校验 IP 格式（filter_var($target, FILTER_VALIDATE_IP)），并避免使用 shell_exec 拼接。

F-2 026.php Windows 分支 ping 命令拼接导致 OS 命令注入（CWE-78）

critical command_injection / CWE-78 · 置信度 0.78 · candidate / rule_verified+llm

位置：026.php:8-10

攻击者通过 HTTP 查询参数 `ip` 提供输入（026.php:5 读取该参数并赋给 `$target`）。程序在 026.php:8 用 `stristr(php_uname('s'), 'Windows NT')` 判断运行平台，命中 Windows 分支后，在 026.php:10 直接把 `$target` 拼接到字符串 `'ping '` 之后交给 `shell_exec()` 执行。代码片段显示拼接前没有任何转义、白名单或参数化处理（无 `escapeshellarg`/`escapeshellcmd`，也无 IP 格式校验），因此 `$target` 中的 shell 元字符（如 `&`、`|`、`;`）会被命令解释器当作命令分隔符执行。

影响：远程未认证攻击者可在 Web 服务器进程权限下执行任意系统命令，导致服务器被完全控制、数据泄露、横向移动与持久化；属于 RCE 级影响。

CVE/CWE 论证：CWE-78（OS 命令注入）。外部可达性：注入点来自 HTTP query 参数 `ip`，无需认证即可触达 026.php:10 的 `shell_exec`；利用链闭合：`ip` → `$target` → 字符串拼接 → `shell_exec`，中间无有效净化。该分支仅在 Windows 主机上生效（026.php:8 平台判断），非 Windows 环境走 026.php:14 的另一条同类汇点。

修复建议：不要用字符串拼接构造 shell 命令。优先使用参数数组形式（如 `proc_open`/`exec` 的数组参数）避免经过 shell；若必须拼接，对 `$target` 使用 `escapeshellarg()` 并配合严格白名单校验（如 `filter_var($target, FILTER_VALIDATE_IP)`），同时以最小权限账户运行 Web 服务。

F-3 026.php *nix 分支 ping -c 4 命令拼接导致 OS 命令注入（CWE-78）

critical command_injection / CWE-78 · 置信度 0.78 · candidate / rule_verified+llm

位置：026.php:12-14

攻击者通过 HTTP 查询参数 `ip` 提供输入（026.php:5 读取并赋给 `$target`）。当 026.php:8 的平台判断不成立（非 Windows NT）时进入 026.php:12 的 else 分支，在 026.php:14 将 `$target` 直接拼接到 `'ping -c 4 '` 之后交给 `shell_exec()`。代码片段中未见任何转义、白名单或参数化处理，`$target` 中的 shell 元字符（`;`、`|`、`&&`、`$()`、反引号等）会被 shell 解释执行。

影响：远程未认证攻击者可在 *nix Web 服务器进程权限下执行任意系统命令，实现 RCE、读取敏感文件、建立持久化后门等，影响为服务器完全失陷。

CVE/CWE 论证：CWE-78（OS 命令注入）。外部可达性：注入点为 HTTP query 参数 `ip`，无需认证即可到达 026.php:14 的 `shell_exec`；利用链闭合：`ip` → `$target` → 字符串拼接 → `shell_exec`，无有效净化。该分支在非 Windows 平台生效，与 026.php:10 的 Windows 分支构成同一参数的两条注入路径。

修复建议：改用不经过 shell 的参数数组方式执行 ping（如 `proc_open` 传数组），或对 `$target` 使用 `escapeshellarg()` 并叠加 `filter_var($target, FILTER_VALIDATE_IP)` 白名单校验；限制 Web 进程权限，避免以高权限账户运行。
