sqli-labs vulnerability sample package

This folder preserves the sqli-labs-relative paths for the selected lesson module and its shared runtime context.
The lesson's pages are kept as a whole module (entry page, registration/login/password-change endpoints and the
side pages they redirect to), because the module is the unit under review. Sibling lessons (Less-1 ... Less-65),
the repository landing page (index.html), the README/tomcat bundle and the mysql provisioning scripts
(sql-connections/setup-db*.php) are deliberately excluded to avoid cross-lesson contamination.

Shared files included: the MySQL connection closure (sql-connections/sql-connect.php and
sql-connections/db-creds.inc) and the database bootstrap (sql-lab.sql: creates the `security` database with the
`users` table and its seed rows). The pages keep their original relative include paths (`../sql-connections/...`),
so Less-24/, sql-connections/ and images/ must stay siblings on deployment.

Images: only the seven images referenced by this module's pages are included. The other 81 images in the
repository belong to other lessons and are excluded.

Case collision note: the upstream repository tracks two entries whose names differ only by case
(`Less-24/Logged-in.php` and `Less-24/logged-in.php`). No page links to the mixed-case one, and it cannot be
materialised on a case-insensitive filesystem, so it is excluded; `Less-24/logged-in.php` is the live page.

Original source: sqli-labs (Audi-1/sqli-labs, commit e96f21776372c8613a7e565106e62bc01a59355e)
Sample: sqli_labs_less24
Module: Less-24
Mirror used for download: https://gitee.com/yangtf/sqli-labs

Deployment (for dynamic probing, outside this package's scope):
  1. import sql-lab.sql into a local MySQL server (root / empty password by default, see db-creds.inc);
  2. copy the package into a PHP web root so that Less-24/ and sql-connections/ are siblings;
  3. open http://HOST/Less-24/index.php (the original code targets the PHP 5 mysql_* extension).
