F-1 025.php ping 功能通过 $_REQUEST['ip'] 造成命令注入（黑名单可绕过）

critical command_injection / CWE-78 · 置信度 0.9 · candidate / llm_inferred

位置：025.php:5-30

脚本在 $_POST['Submit'] 存在时读取 $_REQUEST['ip']（第 5 行），仅用 str_replace 做黑名单替换（第 8-21 行），随后直接拼接进 shell_exec('ping -c 4 ' . $target)（第 30 行，Windows 分支为第 26 行）。黑名单只删除 ||、&、;、'| '、-、$、(、)、` 等子串，未删除换行符 \n、未删除单个 |、未删除 >、<、空格组合等，且 str_replace 是单次顺序替换，可用嵌套构造绕过（例如 '|' 后接被删字符重组）。攻击者可在 ip 参数中注入换行或管道符执行任意系统命令，获得服务器命令执行权限。

影响：远程未授权攻击者可在服务器上执行任意系统命令，完全控制 Web 服务器进程权限，读取敏感文件、横向移动、植入后门。

CVE/CWE 论证：CWE-78 OS 命令注入。外部可达（HTTP 参数 ip），无需认证，source→sink 链完整闭合，黑名单过滤可绕过，属于典型 CVE 级命令注入。

修复建议：不要将用户输入拼接进 shell 命令；使用 escapeshellarg() 对 $target 转义，或改用 filter_var($target, FILTER_VALIDATE_IP) 严格校验为合法 IP 后再拼接；避免使用 shell_exec，改用参数化方式调用。

F-2 025.php Windows 分支 ping 命令拼接导致 OS 命令注入（CWE-78）

critical command_injection / CWE-78 · 置信度 0.78 · candidate / rule_verified+llm

位置：025.php:24-26

攻击者通过 HTTP 查询参数 `ip` 提供输入（025.php:5 读取该参数并赋给 `$target`）。程序在 025.php:24 用 `stristr(php_uname('s'), 'Windows NT')` 判断运行平台，命中 Windows 分支后，在 025.php:26 执行 `$cmd = shell_exec( 'ping ' . $target );`。`$target` 未经任何转义、白名单校验或参数化，直接以字符串拼接方式进入 `shell_exec`，因此 `ip` 中的 shell 元字符（如 `&`、`|`、`;`、`&&`）会被命令解释器解析，从而在 Web 进程权限下执行任意命令。该分支的校验完全缺失，不存在可绕过的净化逻辑。

影响：远程未认证攻击者可在目标主机上以 Web 服务进程权限执行任意系统命令，导致服务器完全失陷（读取/篡改文件、横向移动、植入后门）。Windows 分支下可通过 `&`、`|` 等分隔符追加命令。

CVE/CWE 论证：CWE-78（OS 命令注入）：外部可控的 `ip` 参数经 `$target` 直接拼接到 `shell_exec` 的命令字符串，无参数化或转义。该入口为公开 HTTP 查询参数，无需认证即可到达 025.php:26，利用链闭合（source 025.php:5 → sink 025.php:26）。

修复建议：不要用字符串拼接构造 shell 命令。使用 `escapeshellarg($target)` 对参数做转义，并配合 `escapeshellcmd`；更优做法是用白名单校验 `ip` 仅允许合法 IP/主机名（如 `filter_var($target, FILTER_VALIDATE_IP)` 或严格正则），校验失败直接拒绝；或改用不经过 shell 的 API（如 `proc_open` 传数组参数）并限制 ping 可执行文件路径与最小权限运行。
