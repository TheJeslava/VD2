F-1 046.php 会话标识基于可预测递增计数器（弱 ID，CWE-330）

high weak_id / CWE-330 · 置信度 0.7 · candidate / rule_verified+llm

位置：046.php:5-6

攻击者通过请求携带/接收 dvwaSession Cookie 参与会话。046.php:5 判断 POST 后，第 6 行 if (!isset($_SESSION['last_session_id_high'])) 初始化会话计数器，第 7 行置为 0，第 9 行每次请求自增，第 10 行 md5 后第 11 行写入 Cookie。校验无效的根因是标识的熵源为单调递增整数：取值空间极小且顺序可预测，攻击者无需任何秘密即可枚举出全部可能值（配合 md5 预计算表直接对应），服务端也没有绑定 IP/UA 或做二次校验。最终危险操作是把该可预测值作为会话标识下发并在后续请求中作为身份凭据使用。

影响：会话预测与劫持：攻击者可枚举/推算 dvwaSession 值，冒充其他会话访问受保护页面，造成越权与敏感数据泄露；结合 Cookie 未设 Secure/HttpOnly，还可被中间人或脚本窃取。

CVE/CWE 论证：CWE-330（Use of Insufficiently Random Values）/CWE-340（Generation of Predictable Numbers or Identifiers）：046.php:6-7 以 0 初始化、046.php:9 单调自增作为会话标识来源，熵远低于安全要求。外部可达性：POST 请求即可触发（046.php:5），无需认证。利用链闭合：请求 → 计数器初始化/自增（046.php:6-9）→ md5（046.php:10）→ setcookie 下发（046.php:11）→ 攻击者预测并伪造 Cookie。证据为源码推断，未做动态验证。

修复建议：使用 CSPRNG 生成会话 ID（random_bytes / session_regenerate_id(true)），保证 ≥128 bit 熵且不可预测；登录成功后强制轮换会话 ID；将会话与用户绑定并在服务端校验；Cookie 设置 Secure、HttpOnly、SameSite=Lax/Strict；避免使用自增计数器或时间戳作为标识来源。

F-2 046.php 使用 MD5 生成会话 Cookie 值（弱哈希，CWE-328）

medium weak_crypto / CWE-327 · 置信度 0.72 · candidate / rule_verified+llm

位置：046.php:9-10

攻击者无需输入任何参数：在 046.php 第 5 行判断 REQUEST_METHOD 为 POST 后，第 9 行把 $_SESSION['last_session_id_high'] 自增，第 10 行 $cookie_value = md5($_SESSION['last_session_id_high']) 用 MD5 对一个小整数计数器做摘要，第 11 行通过 setcookie("dvwaSession", $cookie_value, time()+3600, "/vulnerabilities/weak_id/", $_SERVER['HTTP_HOST'], false, false) 下发。校验之所以无效，是因为 MD5 不是为不可预测性设计的：输入空间仅为递增整数（0,1,2,...），攻击者可离线枚举 md5(0)、md5(1)… 建立完整映射表，把 Cookie 值直接还原为计数器值；同时 setcookie 的 secure 与 httponly 两个标志位均为 false，Cookie 可在明文 HTTP 下传输并被脚本读取。最终危险操作是把可预测、可离线反推的摘要值当作会话标识写入客户端 Cookie。注意：该候选原始类型标注为 weak_crypto，但按 CWE 分类，MD5 用于会话标识属 weak_hash（CWE-328），不是 DES/ECB 类加密算法问题（CWE-327）。

影响：会话标识可预测/可伪造：攻击者枚举 md5(小整数) 即可猜出其他用户的 dvwaSession 值，进而劫持会话、以受害者身份访问 /vulnerabilities/weak_id/ 下的功能；由于 Cookie 未设 Secure/HttpOnly，还可经明文信道或 XSS 窃取。影响为身份冒用与越权访问，不涉及 RCE。

CVE/CWE 论证：CWE-328（Use of Weak Hash）：046.php:10 对安全用途（会话 Cookie 值）使用 MD5；CWE-330/CWE-340 辅助说明熵源为可预测递增整数。外部可达性：该逻辑位于 POST 请求处理路径（046.php:5），任何未认证访问者提交 POST 即可触发并获取 Cookie，无需登录、无需特权。利用链闭合：POST → 计数器自增（046.php:9）→ md5 摘要（046.php:10）→ setcookie 下发（046.php:11）→ 攻击者离线枚举映射并伪造 Cookie。证据等级为源码推断，未做运行时验证。

修复建议：改用 CSPRNG 生成会话标识：如 PHP 7+ 的 bin2hex(random_bytes(32)) 或 session_regenerate_id(true)，不要对计数器做摘要；若必须保留派生关系，使用 hash_hmac('sha256', $value, $server_side_secret) 并保证密钥不泄露。同时把 setcookie 的 secure 设为 true、httponly 设为 true，并在全站强制 HTTPS；会话标识应有足够熵（≥128 bit）且不可枚举。

F-3 DVWA weak_id 模块使用自增计数器 md5 生成会话 Cookie（可预测会话 ID）

medium weak_random / CWE-330 · 置信度 0.72 · candidate / llm_inferred

位置：046.php:9-11

046.php 在 POST 请求时把 $_SESSION['last_session_id_high'] 自增后直接 md5() 作为 Cookie `dvwaSession` 的值下发。该值完全由单调递增的整数决定（md5(1)、md5(2)、md5(3)…），不含任何随机源，攻击者可离线枚举全部候选值，从而预测/伪造其他用户的会话标识，属于弱会话 ID 生成（CWE-330/CWE-340）。

影响：会话标识可预测，攻击者可枚举/伪造 dvwaSession，导致会话劫持或身份冒用（在依赖该 Cookie 做身份判定时）。

CVE/CWE 论证：CWE-330 使用不充分的随机值 / CWE-340 可预测的会话标识；无需认证即可通过 POST 触发并观察生成规律，链闭合。

修复建议：使用 CSPRNG（random_bytes/bin2hex 或 session_regenerate_id）生成会话标识，避免由自增计数器派生。
