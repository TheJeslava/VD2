F-1 025.php ping 功能通过 ip 参数导致命令注入（黑名单可绕过）

critical command_injection / CWE-78 · 置信度 0.9 · candidate / llm_inferred

位置：025.php:3-34

脚本在 $_POST['Submit'] 存在时读取 $_REQUEST['ip']，仅用 str_replace 删除黑名单字符（||、&、;、'| '、-、$、(、)、`），随后直接拼接到 shell_exec('ping -c 4 ' . $target)（Windows 分支为 'ping ' . $target）。黑名单不完整：换行符 \n、制表符、以及 '|' 后跟非空格字符（如 '|id'）均未被过滤，且 str_replace 只做一次替换，可用 '||' 变形或换行绕过。攻击者可在 ip 参数中注入任意系统命令，以 Web 服务器权限执行，导致完全 RCE。

影响：未认证远程攻击者可在目标服务器上以 Web 服务器进程权限执行任意系统命令，完全控制服务器（RCE）。

CVE/CWE 论证：CWE-78 OS 命令注入。source（$_REQUEST['ip']）到 sink（shell_exec）链路完整，黑名单可绕过，无需认证即可从外部触发，符合 CVE 申报条件。

修复建议：不要将用户输入拼接到 shell 命令。使用 escapeshellarg() 对 $target 转义，或使用白名单校验 IP 格式（filter_var($target, FILTER_VALIDATE_IP)），并避免使用 shell_exec 拼接。

F-2 025.php Windows 分支 ping 命令拼接导致 OS 命令注入（CWE-78）

critical command_injection / CWE-78 · 置信度 0.83 · candidate / rule_verified+llm

位置：025.php:24-26

攻击者通过 HTTP 查询参数 `ip` 提供输入，该输入在 025.php:5 被读入变量 `target`。代码在 025.php:24 用 `stristr(php_uname('s'), 'Windows NT')` 判断运行平台，命中 Windows 分支后，在 025.php:26 执行 `$cmd = shell_exec( 'ping ' . $target );`。`target` 未经任何转义、白名单校验或参数化处理，直接以字符串拼接方式进入 `shell_exec`，因此 `&`、`|`、`;`、`&&` 等 shell 元字符会被解释为命令分隔符，攻击者可追加任意系统命令。该分支仅在 Windows 主机上触发，属于平台相关的利用条件，但一旦命中即无需认证、外部可达。

影响：远程未认证攻击者可在 Web 服务进程权限下执行任意操作系统命令，导致服务器完全失陷（RCE）、读取/篡改应用与系统文件、横向移动。Windows 分支下可执行 `ip=127.0.0.1 & whoami` 之类的命令。

CVE/CWE 论证：CWE-78（OS Command Injection）：外部可控的查询参数 `ip` 经变量 `target` 未净化拼接进 `shell_exec`，构成 source→sink 闭合链；入口为公开 HTTP 端点，无需认证，攻击者仅需构造 query 即可触发，外部可达性成立。利用条件为运行在 Windows NT 平台（025.php:24 判断），属环境前提而非额外权限要求。

修复建议：不要用字符串拼接构造 shell 命令。优先使用参数数组形式（如 `proc_open`/`escapeshellarg` 配合固定命令），或改用不经过 shell 的库/函数执行 ping；对 `ip` 参数做严格白名单校验（仅允许 IPv4/IPv6 字面量，用 `filter_var($ip, FILTER_VALIDATE_IP)` 校验），校验失败直接拒绝；以最小权限账户运行 Web 服务，禁用不必要的 shell 执行能力。

F-3 025.php *nix 分支 ping 命令拼接导致 OS 命令注入（CWE-78）

critical command_injection / CWE-78 · 置信度 0.83 · candidate / rule_verified+llm

位置：025.php:28-30

攻击者通过 HTTP 查询参数 `ip` 提供输入，该输入在 025.php:5 被读入变量 `target`。当 025.php:24 的平台判断不命中 Windows 时进入 025.php:28 的 else 分支，在 025.php:30 执行 `$cmd = shell_exec( 'ping -c 4 ' . $target );`。`target` 未做任何转义、白名单或参数化，直接字符串拼接进入 `shell_exec`，`;`、`|`、`&&`、`$()`、反引号等 shell 元字符可注入任意命令。该分支覆盖 Linux/Unix 等非 Windows 平台，是更常见的部署环境，外部未认证即可触发。

影响：远程未认证攻击者在 *nix 主机上以 Web 服务进程权限执行任意系统命令（RCE），可读取敏感文件、植入后门、提权与横向移动。例如 `ip=127.0.0.1; id` 会执行 `id`。

CVE/CWE 论证：CWE-78（OS Command Injection）：查询参数 `ip` 经 `target` 未净化拼接进 `shell_exec`，source→sink 链闭合；端点公开、无需认证，外部可达；利用前提仅为非 Windows 平台（025.php:28 分支），属常规部署环境，不构成额外权限门槛。

修复建议：改用参数数组方式执行命令（`proc_open` 传数组参数）或使用不经过 shell 的 ping 实现；对 `ip` 使用 `filter_var($ip, FILTER_VALIDATE_IP)` 严格白名单校验并拒绝非法输入；如必须拼接，使用 `escapeshellarg`/`escapeshellcmd` 并固定命令前缀；以最小权限运行服务。
