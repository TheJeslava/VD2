F-1 011.php 登录接口 username 参数 SQL 注入（可绕过认证）

critical sql_injection / CWE-89 · 置信度 0.9 · candidate / llm_inferred

位置：011.php:5-13

011.php 第 3 行以 $_GET['Login'] 存在为条件进入登录逻辑，第 5 行直接取 $_GET['username'] 赋给 $user，未做任何转义/参数化；第 12 行将 $user 直接拼接进 SELECT 语句，第 13 行通过 mysqli_query 执行。攻击者可在 username 中注入 SQL 语法（如 ' OR '1'='1' -- -）改变查询语义，绕过密码校验以任意用户（含管理员）身份登录，或通过 UNION/布尔盲注读取 users 表全部数据。password 虽经 md5() 处理，但 md5 输出为固定 32 位十六进制，无法注入，故注入点唯一为 username。

影响：未认证攻击者可直接绕过登录认证进入受保护区域，并可进一步通过 UNION/盲注导出 users 表全部账号与口令哈希，导致账户接管与数据泄露。

CVE/CWE 论证：CWE-89 SQL 注入。外部 GET 参数 username 未经任何转义直达 mysqli_query，链路在 CODE PACK 内完整闭合，无需认证，利用门槛极低，符合 CVE/赏金平台接收标准。

修复建议：改用预处理语句（mysqli_prepare + bind_param）绑定 username/password；或至少对 $user 使用 mysqli_real_escape_string 并配合白名单校验；同时避免将数据库错误信息直接输出到页面。

F-3 011.php 使用 MD5 存储/比对口令（CWE-328）

medium weak_crypto / CWE-327 · 置信度 0.76 · candidate / rule_verified+llm

位置：011.php:8-9

011.php:8 从 GET 参数 `password` 读取明文口令，011.php:9 调用 `md5($pass)` 生成摘要，随后在 011.php:12 的 SQL 中与数据库 `password` 字段比对。MD5 为快速、无盐、可碰撞的哈希算法，用于口令等安全用途时无法抵抗离线暴力破解与彩虹表攻击。此处为配置/实现型弱点，不依赖 HTTP 污点链，证据为 011.php:9 的 `md5(` 调用原文。

影响：若数据库泄露，攻击者可用彩虹表或 GPU 高速爆破在极短时间内还原用户明文口令；相同口令产生相同摘要，便于批量撞库与横向移动。注意：该弱点本身不直接导致 RCE，但会放大凭据泄露后果。

CVE/CWE 论证：CWE-328（使用弱哈希算法）。外部可达性：登录接口 011.php:3 无需认证即可触发哈希计算路径。利用链：011.php:8 取明文 → 011.php:9 `md5()` → 011.php:12 与库中摘要比对，属口令安全用途，符合 weak_hash 判定边界（非 CWE-327 加密算法问题）。

修复建议：改用专为口令设计的慢哈希算法，如 `password_hash()`（PASSWORD_ARGON2ID 或 PASSWORD_BCRYPT）并配合 `password_verify()`；为每个口令使用独立随机盐；迁移期可对旧 MD5 摘要做二次加盐哈希；强制口令复杂度与长度策略。

F-4 011.php 登录成功页 username 反射型 XSS

medium xss / CWE-79 · 置信度 0.7 · candidate / llm_inferred

位置：011.php:21-22

第 21 行将 $user（来自 $_GET['username']，第 5 行未做 HTML 编码）直接拼入 $html 输出到页面：$html .= "<p>Welcome to the password protected area {$user}</p>"。虽然进入该分支需登录成功（依赖 SQL 注入或有效凭据），但一旦通过注入恒真条件使查询返回行，攻击者可控的 username 会原样反射到 HTML，形成反射型 XSS，可用于钓鱼或结合社工窃取会话。

影响：反射型 XSS，可在受害者浏览器执行任意脚本，窃取 Cookie/会话或进行钓鱼，需结合注入或有效凭据触发。

CVE/CWE 论证：CWE-79。username 未编码直达 HTML 输出，链路在 CODE PACK 内闭合，但触发依赖登录成功分支，故定为 medium。

修复建议：输出前对 $user 使用 htmlspecialchars($user, ENT_QUOTES, 'UTF-8')；avatar 同样需编码并校验来源。
