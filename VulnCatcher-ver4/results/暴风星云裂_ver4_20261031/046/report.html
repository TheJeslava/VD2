F-1 046.php 会话标识基于自增整数，可预测（CWE-330）

high weak_id / CWE-330 · 置信度 0.6 · candidate / rule_verified+llm

位置：046.php:5-6

046.php:5 在 POST 请求下进入 046.php:6，检查 $_SESSION['last_session_id_high'] 是否存在，不存在则置 0（046.php:7），随后在 046.php:9 自增、046.php:10 用 md5 派生 Cookie 值。会话标识的熵来源是单调递增的整数计数器，而非随机源，攻击者可通过观察自身会话值推断相邻用户的会话标识。

影响：会话预测与劫持：攻击者获取一次自身 dvwaSession 值后，可推算前后用户的令牌（自增序列 + 确定性 md5），实现会话固定/劫持，导致越权访问受害者账户数据。

CVE/CWE 论证：CWE-330（Use of Insufficiently Random Values）：会话标识由计数器派生，缺乏随机性；外部可达性——046.php 为公开 Web 端点，任意 POST 即可触发；利用链闭合——046.php:6/7 初始化 → 046.php:9 自增 → 046.php:10 md5 → 046.php:11 setcookie，序列完全确定，攻击者可离线复现。

修复建议：使用密码学安全随机数生成会话 ID（random_bytes / random_int 配合足够熵），避免任何自增或时间派生；服务端维护会话表并校验绑定信息（IP/UA 指纹可选）；启用 session_regenerate_id 在登录后轮换标识。

F-2 046.php 使用 MD5 生成会话 Cookie 值（弱哈希，CWE-328）

medium weak_crypto / CWE-327 · 置信度 0.76 · candidate / rule_verified+llm

位置：046.php:9-10

攻击者无需输入任何参数：在 046.php:5 判断 REQUEST_METHOD 为 POST 后，046.php:9 将 $_SESSION['last_session_id_high'] 自增，046.php:10 用 md5($_SESSION['last_session_id_high']) 计算 $cookie_value，046.php:11 通过 setcookie("dvwaSession", $cookie_value, time()+3600, "/vulnerabilities/weak_id/", $_SERVER['HTTP_HOST'], false, false) 下发。根因是使用 MD5 这一已被证明存在碰撞、且对短整型输入可被完全预计算的哈希算法来派生安全令牌；同时 setcookie 的 secure 参数为 false、httponly 为 false，令牌可经明文通道传输并被脚本读取。注意：该候选原始类型标注为 weak_crypto，但按证据应归类为 weak_hash（CWE-328），而非 CWE-327 的加密算法误用。

影响：会话标识可预测/可伪造：由于输入空间仅为自增整数，攻击者可在本地枚举 md5(0..N) 建立彩虹表，直接猜解或构造合法 dvwaSession 值，进而劫持其他用户会话（越权访问、身份冒用）。Cookie 未设置 Secure/HttpOnly，进一步扩大泄露面（明文嗅探、XSS 读取）。

CVE/CWE 论证：CWE-328（Use of Weak Hash）：MD5 用于生成会话令牌属安全用途，短整型输入使预计算攻击成本极低；外部可达性——046.php 为 Web 可直接访问脚本，POST 请求即可触发令牌生成，无需认证；利用链闭合——046.php:9 自增 → 046.php:10 md5 派生 → 046.php:11 setcookie 下发，攻击者只需预测/枚举该值即可复用会话。

修复建议：改用 CSPRNG 生成会话标识：random_bytes(32) 或 session_regenerate_id(true)，禁止用 MD5/SHA-1 派生令牌；若必须哈希，使用 hash('sha256', ...) 并配合服务端随机盐与 HMAC。setcookie 增加 secure=true、httponly=true、samesite=Lax/Strict；会话标识应完全随机而非自增计数。
