F-1 027.php ping 功能通过 ip 参数导致命令注入（黑名单仅过滤 && 与 ;）

critical command_injection / CWE-78 · 置信度 0.9 · candidate / llm_inferred

位置：027.php:5-23

脚本在收到 POST 参数 Submit 后，从 $_REQUEST['ip'] 读取用户输入 $target，仅用 str_replace 删除 '&&' 与 ';' 两个子串，随后直接拼接进 shell_exec('ping -c 4 ' . $target)（Windows 分支为 shell_exec('ping ' . $target)）。黑名单未覆盖管道符 |、命令替换 $() 与反引号、换行符、后台符 &、以及 || 等，攻击者可在 ip 参数中注入任意系统命令并以 Web 进程权限执行，形成完整 RCE。

影响：未认证远程攻击者可在服务器上以 Web 进程权限执行任意系统命令，读取敏感文件、横向移动、植入后门，完全控制主机。

CVE/CWE 论证：CWE-78 OS 命令注入。外部可达（HTTP POST 参数 ip），无需认证，source→sink 链路在 027.php 内闭合，黑名单可被 |、$()、反引号等轻易绕过，属典型 CVE 级 RCE。

修复建议：不要将用户输入拼接进 shell 命令；使用 escapeshellarg() 对 $target 转义，或改用白名单校验（仅允许合法 IP/主机名正则），并优先使用参数化方式（如 proc_open 传数组参数）避免经过 shell。

F-2 027.php Windows 分支 ping 命令拼接导致 OS 命令注入（CWE-78）

critical command_injection / CWE-78 · 置信度 0.83 · candidate / rule_verified+llm

位置：027.php:17-19

攻击者通过 HTTP 查询参数 `ip` 提供输入（027.php:5 读取该参数并赋给 $target）。程序未对 $target 做任何白名单、转义或参数化处理，在 Windows 分支（php_uname('s') 含 'Windows NT' 时，027.php:17）直接将其拼接到 shell 命令字符串中：027.php:19 `$cmd = shell_exec( 'ping ' . $target );`。由于 shell_exec 通过系统 shell 执行，拼接进命令的 `&`、`|`、`&&`、`;`（Windows 下 cmd 语义）等元字符会被解释为命令分隔符，从而执行攻击者附加的任意命令。校验无效的原因：代码中不存在 escapeshellarg/escapeshellcmd、不存在 IP 格式校验、不存在命令参数数组形式调用，污点从 027.php:5 直达 027.php:19 汇点。

影响：远程命令执行（RCE）：攻击者无需认证即可在 Web 服务器进程权限下执行任意系统命令，可读取/篡改应用与系统文件、窃取数据库凭据、横向移动，完全失陷主机。

CVE/CWE 论证：CWE-78（OS Command Injection）。外部可达性：入口为 HTTP query 参数 `ip`，属公网可访问的 Web 端点；无需认证：代码片段中未见任何鉴权/会话校验；利用链闭合：027.php:5 读取 `ip` → $target → 027.php:19 shell_exec 字符串拼接，中间无净化，攻击者可控命令分隔符即可闭合利用链。

修复建议：1) 不要用 shell 拼接：改用参数数组形式，如 `exec('ping', [$target])`（PHP 8+ 的 proc_open 数组形式）或直接使用 PHP 原生网络函数（如 `gethostbyname`/socket）替代调用系统 ping；2) 若必须调用外部程序，对 $target 做严格白名单校验（仅允许 IPv4/IPv6 字面量，用 `filter_var($target, FILTER_VALIDATE_IP)`），并配合 `escapeshellarg()`；3) 以最小权限运行 Web 进程，禁用不必要的危险函数（disable_functions 中限制 shell_exec/exec/system）。
