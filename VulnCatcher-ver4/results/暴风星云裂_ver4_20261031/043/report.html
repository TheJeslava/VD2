F-1 043.php 不安全文件上传导致任意文件写入（CWE-434）

critical file_upload / CWE-434 · 置信度 0.78 · candidate / rule_verified+llm

位置：043.php:18-20

攻击者通过 HTTP 文件上传字段 `uploaded` 提交文件（043.php:12 读取上传内容并写入 `$uploaded_tmp`），代码随后在 043.php:20 直接调用 `move_uploaded_file( $uploaded_tmp, $target_path )` 将临时文件移动到 `$target_path`。从给出的代码片段看，在 043.php:12 到 043.php:20 之间没有出现扩展名白名单、MIME 校验、文件内容检查或目标路径规范化等有效校验，因此攻击者可以控制上传文件的原始文件名/内容，使 `$target_path` 指向 Web 可访问目录并写入可执行脚本。由于校验缺失，污点从上传字段直达文件写入汇点，利用链闭合。

影响：任意文件写入：攻击者可将 .php 等可执行脚本上传至 Web 根目录，通过访问该文件触发服务端代码执行，进而导致远程代码执行（RCE）、服务器失陷、数据泄露与横向移动；即使不可执行，也可覆盖或投放任意文件造成完整性破坏。

CVE/CWE 论证：CWE-434（Unrestricted Upload of File with Dangerous Type）。外部可达性：上传入口为 HTTP 请求的 `uploaded` 文件字段，无需认证即可访问（证据中未见鉴权逻辑）。利用链闭合：source（043.php:12 上传字段）→ `$uploaded_tmp` → sink（043.php:20 `move_uploaded_file`）之间无有效净化，攻击者完全控制写入内容与目标路径，满足无需认证的外部可利用条件。

修复建议：1) 对上传文件实施扩展名白名单校验（仅允许业务必需类型），并基于服务端解析的真实 MIME/文件头而非客户端 Content-Type 判断；2) 使用 `pathinfo()` 提取扩展名后与白名单严格比对，拒绝双扩展名与大小写绕过；3) 将上传目录置于 Web 根之外，或对上传目录禁用脚本执行（如 PHP 引擎关闭、`Content-Disposition: attachment`）；4) 上传后重命名为随机文件名，避免攻击者控制路径；5) 对 `$target_path` 做 `realpath()` 规范化并校验其位于允许目录内，防止路径穿越；6) 限制文件大小并配合最小权限运行 Web 进程。

F-2 DVWA 文件上传端点（043.php）仅校验扩展名与 getimagesize，可上传含 PHP 代码的图片并写入 hackable/uploads/ 导致远程代码执行

high file_upload / CWE-434 · 置信度 0.8 · candidate / llm_inferred

位置：043.php:3-27

043.php 在收到 POST 参数 Upload 后，直接取 $_FILES['uploaded']['name'] 经 basename() 拼接到 $target_path（DVWA_WEB_PAGE_TO_ROOT."hackable/uploads/"），并用 move_uploaded_file() 落盘。校验仅有三个条件：扩展名（substr 取最后一个点之后）小写后属于 jpg/jpeg/png、文件大小 < 100000 字节、getimagesize() 返回真。getimagesize() 只检查文件头是否为合法图片，不阻止文件尾部附加任意 PHP 代码（图片马）；扩展名检查只看最后一个点后的字符串，攻击者可将文件名设为 shell.php.jpg 或 shell.jpg.php 之类，最终落盘文件名由 basename() 原样保留，若服务器对 .php 后缀解析（或利用多后缀/解析漏洞），即可执行任意 PHP 代码。攻击者无需认证即可通过该端点写入 webshell，形成 RCE。

影响：未授权攻击者可上传并执行任意 PHP 代码，获取服务器控制权，读取/篡改数据库与文件系统。

CVE/CWE 论证：CWE-434 不受限制的危险类型文件上传。外部可达（POST 上传端点），无需认证，校验可被图片马与多后缀绕过，链闭合至 move_uploaded_file 落盘并可执行。

修复建议：使用白名单校验扩展名并重命名文件为随机名+固定安全扩展名；用 finfo/getimagesize 结合内容重编码图片剥离附加代码；将上传目录置于 Web 根之外或禁用该目录 PHP 解析；限制文件大小与 MIME。
