F-1 026.php ping 功能通过 $_REQUEST['ip'] 拼接 shell_exec 导致命令注入（RCE）

critical command_injection / CWE-78 · 置信度 0.9 · candidate / llm_inferred

位置：026.php:5-14

026.php 在收到 POST 参数 Submit 后，直接从 $_REQUEST['ip'] 读取用户输入并赋值给 $target，未做任何白名单、转义（escapeshellarg/escapeshellcmd）或格式校验，随后在第 10 行（Windows 分支）与第 14 行（*nix 分支）将 $target 直接字符串拼接到 shell_exec('ping ...' . $target) 中执行。攻击者可通过在 ip 参数中注入 shell 元字符（如 ; | & $() 反引号）在服务器上执行任意系统命令，获得远程代码执行。

影响：未认证远程攻击者可在 Web 服务器进程权限下执行任意系统命令，完全控制主机，读取敏感文件、横向移动。

CVE/CWE 论证：CWE-78 OS 命令注入。source（$_REQUEST['ip']）到 sink（shell_exec 字符串拼接）链路完整闭合，无任何过滤，外部无需认证即可触发，属典型 RCE。

修复建议：不要将用户输入拼接进 shell 命令；使用 escapeshellarg($target) 转义，或改用参数数组形式（如 proc_open 传数组），并对 ip 做严格 IP 格式校验（filter_var FILTER_VALIDATE_IP）。

F-2 026.php Windows 分支 ping 命令拼接导致 OS 命令注入（CWE-78）

critical command_injection / CWE-78 · 置信度 0.78 · candidate / rule_verified+llm

位置：026.php:8-10

攻击者通过 HTTP 查询参数 `ip` 提供输入，该参数在 026.php:5 被读入变量 `target`。026.php:8 使用 `stristr(php_uname('s'), 'Windows NT')` 判断运行平台，命中 Windows 分支后，026.php:10 执行 `$cmd = shell_exec( 'ping ' . $target );`，将 `target` 未经任何转义、白名单校验或参数化直接拼接到 shell 命令字符串中。由于 `shell_exec` 会把整串交给系统 shell 解析，`target` 中的 `&`、`|`、`&&`、`;`（Windows cmd 下为 `&`、`|`、`&&`）等元字符会被解释为命令分隔符，从而在 Web 进程权限下执行任意命令。代码中不存在 escapeshellarg/escapeshellcmd、正则白名单或 IP 格式校验，因此校验完全缺失。

影响：远程未认证攻击者可在目标主机上以 Web 服务进程权限执行任意系统命令，导致服务器完全失陷：读取任意文件与配置、窃取数据库凭据、写入 WebShell、横向移动。属于 RCE 级别影响。

CVE/CWE 论证：CWE-78（OS 命令注入）。外部可达性：注入点为 HTTP query 参数 `ip`，无需认证即可访问 026.php。利用链闭合：`ip` → `target`（026.php:5）→ 字符串拼接（026.php:10）→ `shell_exec` 执行。校验无效原因：全程无转义、无白名单、无类型约束，shell 元字符直接生效。该分支仅在 Windows 主机触发，属环境相关但代码路径确定。

修复建议：不要通过 shell 拼接执行 ping。改用参数数组形式并禁用 shell，例如 PHP 中用 `proc_open` 传入参数数组，或直接使用 `filter_var($target, FILTER_VALIDATE_IP)` 严格校验为合法 IP 后再以数组参数调用；对输入做白名单（仅允许 IPv4/IPv6 字面量），拒绝包含任何 shell 元字符的输入；以最小权限账户运行 Web 服务。
