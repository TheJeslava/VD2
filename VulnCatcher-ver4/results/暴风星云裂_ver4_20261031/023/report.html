F-1 023.php 口令更新语句 SQL 注入（CWE-89）

critical sql_injection / CWE-89 · 置信度 0.55 · candidate / rule_verified+llm

位置：023.php:15-17

攻击者通过 GET 参数 password_new（023.php:5 `$pass_new = $_GET['password_new'];`）提交输入。该值在 023.php:11 仅经过 mysqli_real_escape_string 处理，随后在 023.php:16 被直接拼接进 UPDATE 语句：`$insert = "UPDATE `users` SET password = '$pass_new' WHERE user = '" . $current_user . "';";`，并在 023.php:17 交给 mysqli_query 执行。由于拼接发生在字符串构造阶段而非参数化绑定，引号转义无法阻止注入语义（例如在已转义引号之外利用注释符/多语句或改变 WHERE 条件），且 023.php:17 的 die(mysqli_error(...)) 会把数据库错误回显给攻击者，构成报错型注入辅助通道。注意：候选给出的 source 描述为“query `password_new`”，实际注入点是 GET 参数 password_new，POC 应使用该参数名。

影响：可越权修改 users 表中任意用户（含 admin）的 password 字段，实现账户接管；借助报错回显可逐步枚举数据库结构，进一步读取其他表数据（数据泄露）。

CVE/CWE 论证：CWE-89：外部可控输入未经参数化直接进入 SQL 语句。攻击面为 HTTP GET 参数，无需认证即可构造请求（是否要求已登录取决于部署，但注入点本身不依赖任何权限校验），利用链闭合：$_GET['password_new'] → $pass_new → $insert 字符串拼接 → mysqli_query 执行。

修复建议：改用预处理语句与参数绑定（mysqli_prepare + bind_param 或 PDO prepared statement），彻底移除字符串拼接；对 password_new 做长度与字符白名单校验；关闭生产环境的 mysqli_error 回显，改为记录服务端日志；数据库账户遵循最小权限，仅授予必要表的 UPDATE 权限。

F-4 023.php 使用无盐 MD5 存储用户密码

medium weak_hash / CWE-328 · 置信度 0.8 · candidate / llm_inferred

位置：023.php:12-17

第 12 行 `$pass_new = md5( $pass_new );` 将用户新密码以无盐 MD5 存储到 users 表（第 16-17 行）。MD5 属快速哈希，无盐且无迭代，一旦数据库泄露可被彩虹表/GPU 快速还原，且相同密码产生相同哈希。

影响：数据库泄露时用户口令可被快速还原，且相同口令哈希相同，扩大横向影响。

CVE/CWE 论证：CWE-328 使用弱哈希算法。源码直接可见，属实现层弱点。

修复建议：改用 password_hash()/password_verify()（bcrypt/argon2）并加盐。

F-6 023.php 使用 MD5 存储口令（CWE-328）

medium weak_crypto / CWE-327 · 置信度 0.6 · candidate / rule_verified+llm

位置：023.php:11-12

023.php:12 `$pass_new = md5( $pass_new );` 对口令使用 MD5 做单次无盐哈希后写入 users 表。MD5 属于已破解的快速哈希算法，存在大量彩虹表与 GPU 高速碰撞/暴力破解能力，且此处未加盐，相同口令产生相同摘要，可被批量比对。该弱点为配置/实现型，不依赖 HTTP 污点链，证据为 023.php:12 的算法调用原文。

影响：一旦数据库泄露（可与本文件 SQL 注入/报错回显结合），攻击者可在极短时间内还原用户明文口令，导致账户接管与口令复用扩散。

CVE/CWE 论证：CWE-328（Use of Weak Hash）：MD5 用于口令这一安全用途。外部可达性体现在口令经 023.php:5 输入并在 023.php:12 哈希后落库；无需认证即可通过注入读取摘要，利用链闭合。注意此处归类为 weak_hash 而非 weak_crypto（后者指 DES/ECB 等加密算法缺陷）。

修复建议：改用 Argon2id、bcrypt 或 PBKDF2 等带盐、可调工作因子的口令哈希算法（PHP 可用 password_hash/password_verify）；迁移时对存量 MD5 摘要在下次登录时透明重哈希；禁止在任何新代码中使用 md5/sha1 处理口令。
