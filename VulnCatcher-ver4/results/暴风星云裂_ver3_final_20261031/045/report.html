F-1 045.php 不安全文件上传导致任意文件写入（CWE-434）

critical file_upload / CWE-434 · 置信度 0.6 · candidate / rule_verified+llm

位置：045.php:16-18

攻击者通过 multipart/form-data 请求向 045.php 提交文件字段 `uploaded`，PHP 将临时文件路径放入 `$_FILES['uploaded']['tmp_name']`，脚本在 045.php:18 直接调用 `move_uploaded_file($_FILES['uploaded']['tmp_name'], $target_path)` 将其移动到目标目录。输入中给出的代码片段（045.php:16-18）只显示移动动作，未显示对扩展名、MIME 类型、文件内容或目标文件名的任何白名单校验；`$target_path` 的构造逻辑位于片段之外，证据不足，无法确认其是否包含原始文件名或是否被规范化。因此可确认的危险点是：外部可控的上传内容被持久化写入服务器文件系统，且缺少可见的类型/扩展名校验。

影响：若目标目录位于 Web 可访问路径且允许脚本扩展名落地，攻击者可上传 PHP 等可执行脚本，通过后续 HTTP 请求触发，形成远程代码执行（RCE）；即使不可执行，也可造成任意文件写入/覆盖、磁盘占用，并可能作为钓鱼页面或恶意文件分发点，影响服务器完整性与可用性。

CVE/CWE 论证：对应 CWE-434（Unrestricted Upload of File with Dangerous Type）。外部可达性：045.php 为可直接请求的脚本端点，上传字段 `uploaded` 无需认证即可提交（片段中未见任何鉴权逻辑）；利用链闭合：`$_FILES['uploaded']['tmp_name']` → `move_uploaded_file()` → 目标路径落盘，中间无可见的扩展名/MIME/内容校验。证据等级为 llm_inferred：`$target_path` 的赋值与目录可访问性未在片段中给出，故 RCE 结论依赖该前提。

修复建议：1) 对上传文件使用扩展名白名单（如仅 jpg/png/pdf），并结合 `finfo_file()`/`getimagesize()` 校验真实 MIME 与文件头，不信任客户端 `Content-Type`；2) 由服务端生成随机文件名（如 `bin2hex(random_bytes(16))` + 白名单后缀），不使用用户提供的文件名；3) 将上传目录置于 Web 根之外，或通过下载脚本以 `Content-Disposition: attachment` 输出；4) 上传目录禁用脚本执行（如 Nginx `location ~ \.php$ { deny all; }`）；5) 限制文件大小与请求体大小，并以最小权限账户运行 Web 进程；6) 对 `$target_path` 做 `realpath()` 规范化并校验其位于允许目录内，防止路径穿越。

F-2 DVWA 文件上传端点仅校验客户端可控的 MIME 类型，可上传任意 PHP 脚本导致远程代码执行

high file_upload / CWE-434 · 置信度 0.93 · candidate / llm_inferred

位置：045.php:3-25

045.php 在收到 POST 参数 Upload 时，将上传文件移动到 DVWA_WEB_PAGE_TO_ROOT."hackable/uploads/" 目录，文件名取自 $_FILES['uploaded']['name'] 经 basename() 处理。唯一的“是否图片”校验使用 $_FILES['uploaded']['type']（即 HTTP 请求中的 Content-Type，完全由客户端控制）与 $_FILES['uploaded']['size']（同样由客户端声明）。攻击者只需在 multipart 请求中把文件 Content-Type 伪造成 image/jpeg 或 image/png，即可上传任意扩展名（如 .php）的脚本到 Web 可访问的 uploads 目录，随后直接请求该文件触发 PHP 执行，实现远程代码执行。代码未做扩展名白名单、未做 getimagesize() 真实内容校验、未做文件重命名。

影响：任意文件上传导致远程代码执行，攻击者可完全控制 Web 服务器，读取/篡改数据、横向移动。

CVE/CWE 论证：CWE-434 无限制危险类型文件上传。外部 HTTP 直接可达，无需认证，校验仅依赖客户端可控 MIME，链完整闭合。

修复建议：使用 getimagesize()/finfo 做服务端真实类型检测；对扩展名做白名单；上传文件重命名为随机名并去除可执行扩展；将上传目录配置为禁止脚本执行。
