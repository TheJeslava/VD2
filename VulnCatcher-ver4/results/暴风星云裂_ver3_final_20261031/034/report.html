medium open_redirect / CWE-601 · 置信度 0.82 · candidate / llm_inferred

位置：034.php:3-6

脚本从 $_GET['redirect'] 读取目标地址，仅用 strpos($_GET['redirect'], "info.php") !== false 判断子串是否出现，随后直接 header("location: " . $_GET['redirect']) 跳转。校验只要求 URL 任意位置包含子串 info.php，未做协议/主机白名单、未用 parse_url 校验 host、未强制相对路径，因此攻击者可构造 https://attacker/info.php 或 //attacker/info.php 等外部地址通过校验，实现开放重定向，可用于钓鱼、OAuth token 窃取、绕过 SSRF 白名单等。

影响：攻击者可借助受信任域名构造钓鱼链接、窃取 OAuth/SSO 回调中的令牌或绕过下游基于域名的白名单校验。

CVE/CWE 论证：CWE-601 URL 重定向到不可信站点。外部 GET 参数直达 Location 头，校验仅为子串包含，链闭合，无需认证。

修复建议：使用 parse_url 校验 scheme 与 host 白名单，或仅允许固定的相对路径（如 /info.php），拒绝包含 :// 或 // 开头的值；不要用子串包含作为安全判断。
