F-1 025.php ping 功能通过 $_REQUEST['ip'] 造成命令注入（黑名单可绕过）

critical command_injection / CWE-78 · 置信度 0.9 · candidate / llm_inferred

位置：025.php:5-30

025.php 在收到 POST 参数 Submit 后，从 $_REQUEST['ip'] 读取攻击者可控输入 $target，仅用 str_replace 做黑名单替换（过滤 ||、&、;、'| '、-、$、(、)、`），随后直接拼接进 shell_exec('ping -c 4 ' . $target)（Windows 分支为 shell_exec('ping ' . $target)）。黑名单未过滤换行符 \n、空格、重定向符 >、<、以及未被列出的管道写法（如 '|' 后不带空格、'||' 被替换后残留等），且 str_replace 是单次替换，可用双写绕过（如 '||' 被替换为空后仍可构造）。攻击者可通过换行符或空格+重定向/管道注入任意系统命令，实现远程代码执行。

影响：未认证攻击者可在服务器上执行任意系统命令，完全控制 Web 服务器，读取/篡改数据、横向移动。

CVE/CWE 论证：CWE-78 OS 命令注入。外部 HTTP 参数 ip 直接进入 shell_exec，黑名单可绕过，无需认证，链路在单文件内闭合。

修复建议：不要将用户输入拼接进 shell 命令；使用 escapeshellarg() 对 $target 转义，或使用白名单校验 IP 格式（filter_var($target, FILTER_VALIDATE_IP)），并避免使用 shell_exec。

F-2 025.php Windows 分支 ping 命令拼接导致 OS 命令注入（CWE-78）

critical command_injection / CWE-78 · 置信度 0.83 · candidate / rule_verified+llm

位置：025.php:24-26

攻击者通过 HTTP 查询参数 `ip` 提供输入，该输入在 025.php:5 被读入变量 `target`，随后未经任何转义或白名单校验，在 025.php:24 判断 `php_uname('s')` 含 'Windows NT' 时进入 Windows 分支，于 025.php:26 直接拼接进 `shell_exec('ping ' . $target)`。由于 `shell_exec` 将整串交给系统 shell 解释，`target` 中的 `&`、`|`、`&&`、`;` 等元字符会被 shell 当作命令分隔符执行，校验完全缺失，污点直达危险汇点。

影响：远程未认证攻击者可在 Web 服务器进程权限下执行任意系统命令，导致服务器完全失陷（RCE）、敏感文件读取、内网横向移动与持久化。

CVE/CWE 论证：CWE-78（OS 命令注入）。外部可达性：注入点为公开 HTTP 查询参数 `ip`，无需认证；利用链闭合：`ip` → `target`（025.php:5）→ `shell_exec('ping ' . $target)`（025.php:26），中间无净化、无参数化、无白名单，攻击者可控字符串直接进入 shell 解释器，满足命令注入的全部要素。

修复建议：不要用字符串拼接构造 shell 命令。改用参数化执行，例如在 PHP 中用 `escapeshellarg($target)` 包裹参数并配合 `escapeshellcmd`，或使用 `proc_open` 传入参数数组；同时对 `ip` 做严格白名单校验（仅允许 IPv4/IPv6 字面量，如 `filter_var($target, FILTER_VALIDATE_IP)`），校验失败直接拒绝；以最小权限账户运行 Web 服务。
