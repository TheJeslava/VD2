F-1 027.php ping 功能通过 ip 参数导致命令注入（黑名单仅过滤 && 与 ;）

critical command_injection / CWE-78 · 置信度 0.9 · candidate / llm_inferred

位置：027.php:5-23

脚本在 $_POST['Submit'] 存在时，从 $_REQUEST['ip'] 读取用户输入（第 5 行），仅用 str_replace 删除 '&&' 与 ';' 两个子串（第 8-14 行），随后直接拼接进 shell_exec('ping -c 4 ' . $target)（*nix，第 23 行）或 shell_exec('ping ' . $target)（Windows，第 19 行）。黑名单未过滤管道符 '|'、后台执行 '&'、换行、反引号、$() 等，攻击者可在 ip 参数中注入任意命令并以 Web 服务器权限执行，形成完整 RCE。

影响：未认证远程攻击者可在 Web 服务器权限下执行任意系统命令，完全控制主机，读取敏感文件、横向移动。

CVE/CWE 论证：CWE-78 OS 命令注入。外部 HTTP 参数 ip 直达 shell_exec，黑名单不完整可绕过，无需认证，链路在 CODE PACK 内完全闭合。

修复建议：避免将用户输入拼接进 shell 命令；使用 escapeshellarg() 对 $target 转义，或改用白名单校验（仅允许合法 IP/主机名正则），并禁用不必要的 shell_exec。

F-2 027.php Windows 分支 ping 命令拼接导致 OS 命令注入（CWE-78）

critical command_injection / CWE-78 · 置信度 0.83 · candidate / rule_verified+llm

位置：027.php:17-19

攻击者通过 HTTP 查询参数 `ip` 提供输入（027.php:5 读取到 `$target`），该值未经任何转义或白名单校验，在 Windows 分支（`stristr(php_uname('s'),'Windows NT')` 为真，027.php:17）被直接字符串拼接到 `shell_exec('ping ' . $target)`（027.php:19）。由于拼接发生在 shell 解释之前，`$target` 中的 `&`、`|`、`;`、`&&` 等 shell 元字符会被命令解释器当作命令分隔符执行，从而在 Web 服务器进程权限下执行任意系统命令。校验无效的原因：代码中不存在 escapeshellarg/escapeshellcmd、不存在 IP 格式白名单、不存在参数化调用（如 proc_open 数组形式），仅做平台判断后直接拼接。

影响：远程未认证攻击者可在目标主机上以 Web 服务进程权限执行任意操作系统命令，导致服务器完全失陷（读取/篡改文件、横向移动、植入后门）。属于 RCE 级别影响。

CVE/CWE 论证：CWE-78（OS Command Injection）。外部可达性：入口为 HTTP query 参数 `ip`，无需认证即可访问 027.php；利用链闭合：source（027.php:5 的 `ip`）→ 变量 `$target` → 无净化 → sink（027.php:19 `shell_exec`），Windows 平台分支下必然触发。

修复建议：不要通过 shell 拼接执行 ping：改用参数数组形式（如 `proc_open(['ping', $target], ...)`）或 PHP 的 `filter_var($target, FILTER_VALIDATE_IP)` 严格校验并拒绝非 IP 输入；若必须调用 shell，使用 `escapeshellarg($target)` 并对 IP 做白名单/正则校验；同时以最小权限运行 Web 进程。
