F-1 045.php 不安全文件上传导致任意文件落盘（CWE-434）

critical file_upload / CWE-434 · 置信度 0.73 · candidate / rule_verified+llm

位置：045.php:16-18

攻击者通过 HTTP 多部分表单上传文件，文件内容进入 PHP 超全局数组 $_FILES['uploaded']（045.php:18 引用的上传字段名为 uploaded）。代码在 045.php:18 直接调用 move_uploaded_file($_FILES['uploaded']['tmp_name'], $target_path)，把客户端提交的临时文件移动到 $target_path 指定的目标路径。输入中给出的片段仅覆盖第 16-18 行，未展示 $target_path 的构造过程，也未展示任何扩展名白名单、MIME 校验、getimagesize() 内容校验、文件重命名或目标目录禁止脚本执行的配置，因此从可见证据看不存在有效净化。校验无效的原因：上传文件名/内容完全由客户端控制，服务端仅做“移动”动作，未对扩展名与内容做约束，攻击者可提交 .php 等可执行扩展名文件。最终危险操作是 move_uploaded_file 将攻击者可控内容写入 Web 可访问目录。

影响：若目标目录位于 Web 根且允许 PHP 解析，攻击者可上传 webshell 并访问对应 URL，实现远程代码执行（RCE），进而读取数据库配置、窃取业务数据、横向移动；即使不可解析，也可造成任意文件落盘、磁盘占满、覆盖既有文件（取决于 $target_path 是否含用户可控文件名）。

CVE/CWE 论证：CWE-434（Unrestricted Upload of File with Dangerous Type）。外部可达性：上传入口为 HTTP 表单字段 uploaded，无需认证即可访问该脚本（片段中未见任何鉴权/session 校验）。利用链闭合：客户端上传 → $_FILES['uploaded']['tmp_name'] → move_uploaded_file 落盘到 $target_path，中间无白名单/内容校验。证据等级为 llm_inferred：$target_path 的赋值与目录可执行性未在给定片段中出现，故 RCE 结论依赖该前提。

修复建议：1) 使用扩展名白名单（如仅 jpg/png/gif/pdf）并基于服务端解析的真实内容（getimagesize/finfo）校验，不信任 $_FILES['uploaded']['name'] 与 Content-Type；2) 由服务端生成随机文件名，禁止使用客户端文件名拼接 $target_path，防止路径穿越与覆盖；3) 上传目录置于 Web 根之外，或通过 Web 服务器配置禁用该目录的脚本解析（如 php_flag engine off / 禁止 .php 执行）；4) 限制文件大小与数量，设置目录最小权限；5) 上传后做病毒/内容扫描并按需重命名归档。

F-2 DVWA 文件上传端点仅校验客户端可控的 MIME 类型，可上传任意 PHP 脚本导致远程代码执行

high file_upload / CWE-434 · 置信度 0.88 · candidate / llm_inferred

位置：045.php:3-26

045.php 在收到 POST 参数 Upload 时，将上传文件保存到 DVWA_WEB_PAGE_TO_ROOT . "hackable/uploads/" 目录，文件名取自 $_FILES['uploaded']['name'] 经 basename() 处理。唯一的“图片校验”是 $uploaded_type == "image/jpeg" || "image/png"，而 $uploaded_type 直接来自 $_FILES['uploaded']['type']（第 10 行），该值完全由客户端 multipart 请求的 Content-Type 头决定，攻击者可任意伪造。代码未做扩展名白名单、未做 getimagesize()/finfo 内容检测、未重命名文件、未禁止 .php 扩展名，因此攻击者可上传内容为 PHP 代码、Content-Type 声明为 image/jpeg 的文件（如 shell.php），文件被 move_uploaded_file 落到 Web 可访问的 uploads 目录，随后访问该文件即可执行任意 PHP 代码，形成 RCE。

影响：攻击者无需认证即可在服务器上写入并执行任意 PHP 代码，完全控制 Web 应用与服务器，可读取数据库配置、横向移动。

CVE/CWE 论证：CWE-434 无限制文件上传 / CWE-646 依赖不可信文件类型。外部可达（HTTP POST），无需认证，source→sink 链在 045.php 内闭合，MIME 校验可被客户端伪造绕过，落盘后可执行，属 RCE 级别。

修复建议：服务端使用 finfo/getimagesize 校验真实文件内容；对扩展名做白名单并强制重命名（如随机名 + 固定图片扩展名）；将上传目录置于 Web 根之外或禁用该目录的脚本执行（php_flag engine off / 移除 handler）；限制文件大小并校验。
