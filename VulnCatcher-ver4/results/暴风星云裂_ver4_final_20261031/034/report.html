F-1 034.php 通过 redirect 参数与 strpos 子串校验实现开放重定向

medium open_redirect / CWE-601 · 置信度 0.82 · candidate / llm_inferred

位置：034.php:3-6

脚本从 $_GET['redirect'] 读取跳转目标，仅用 strpos($_GET['redirect'], "info.php") !== false 判断参数值中是否包含子串 info.php，随后直接 header("location: " . $_GET['redirect']) 跳转。该校验是子串包含而非同源/白名单校验，攻击者可构造包含 info.php 子串的外部 URL（如 https://evil.example/info.php 或 //evil.example/info.php），使服务端返回 302 跳转到攻击者控制的站点，用于钓鱼、OAuth/SSO 令牌窃取或绕过下游基于该跳转的可信域假设。

影响：攻击者可借助可信域名的跳转链接实施钓鱼、窃取凭据或配合 OAuth 回调劫持令牌；用户看到的是可信域发起的跳转。

CVE/CWE 论证：CWE-601 URL 重定向到不可信站点。外部无需认证即可通过 GET 参数触发，校验为子串包含可被轻易绕过，source→sink 链在 034.php:3-5 完整闭合。

修复建议：改为严格白名单或仅允许相对路径：解析 URL 后校验 host 属于本站且 path 精确匹配 /info.php，或使用固定映射表将标识映射到目标路径，禁止直接拼接用户输入到 Location 头。
