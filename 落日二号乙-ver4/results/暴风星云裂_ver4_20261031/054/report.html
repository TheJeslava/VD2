F-1 054.php 反射型 XSS：str_replace 仅过滤小写 <script> 且显式关闭 X-XSS-Protection

medium xss / CWE-79 · 置信度 0.88 · candidate / llm_inferred

位置：054.php:6-11

054.php 第 6 行从 $_GET['name'] 读取外部输入，第 8 行仅用 str_replace('<script>','',...) 做单次、大小写敏感、非递归的黑名单替换，第 11 行将结果直接拼接进 HTML 片段 $html 并输出。由于过滤只匹配精确小写字符串 <script>，攻击者可用 <SCRIPT>、<ScRiPt>、<img src=x onerror=...>、<svg onload=...> 等任意变体绕过；同时第 3 行 header("X-XSS-Protection: 0") 主动关闭浏览器内置 XSS 过滤器，进一步降低利用门槛。该脚本无认证、无 CSRF token、无输出编码，任意访问者构造链接即可在受害者浏览器上下文执行脚本，可窃取会话 Cookie、伪造页面内容或发起钓鱼。

影响：反射型 XSS：攻击者可在受害者浏览器中以目标站点源执行任意 JavaScript，窃取同域 Cookie/令牌、读取页面敏感数据、发起 CSRF 式操作或实施钓鱼；第 3 行关闭 X-XSS-Protection 使旧版浏览器防护失效。

CVE/CWE 论证：CWE-79（Improper Neutralization of Input During Web Page Generation）。外部无需认证即可通过 GET 参数触发，source（054.php:6）→ 弱过滤（054.php:8）→ HTML 输出汇点（054.php:11）链路在 CODE PACK 内完整闭合，且过滤可被大小写/非 script 标签绕过，属可申报的真实反射型 XSS。

修复建议：对输出使用 htmlspecialchars($name, ENT_QUOTES | ENT_SUBSTITUTE, 'UTF-8') 进行 HTML 上下文编码；移除 header("X-XSS-Protection: 0")，改为 X-XSS-Protection: 1; mode=block 或依赖 CSP；不要依赖黑名单替换，采用白名单或上下文编码；增加 Content-Security-Policy 限制内联脚本。
