F-1 044.php 不安全文件上传导致任意文件写入（CWE-434）

critical file_upload / CWE-434 · 置信度 0.83 · candidate / rule_verified+llm

位置：044.php:7-9

攻击者通过 HTTP 多部分表单上传文件，文件内容进入 PHP 超全局数组 $_FILES['uploaded']，其临时路径 $_FILES['uploaded']['tmp_name'] 在 044.php:9 被直接作为源参数传给 move_uploaded_file()，目标路径为变量 $target_path。代码片段显示第 8 行注释为“Can we move the file to the upload folder?”，第 9 行仅判断移动是否成功，未对上传文件的扩展名、MIME 类型、文件内容做任何白名单校验，也未对 $target_path 做规范化或限制在固定目录内。由于校验缺失，攻击者可控制上传文件的原始文件名/内容，使 $target_path 指向 Web 可访问目录下的可执行脚本（如 .php），从而将任意内容落盘。证据仅覆盖 044.php:7-9，$target_path 的构造位置不在 code_pack 范围内，其具体拼接方式（是否使用 $_FILES['uploaded']['name']）证据不足，但第 9 行缺少任何类型/扩展名校验这一事实已足以支撑不安全上传判定。

影响：任意文件写入：攻击者可将恶意 PHP/脚本文件写入 Web 根目录可访问路径，随后通过 HTTP 请求触发执行，形成远程代码执行（RCE），进而读取数据库配置、篡改站点内容、横向移动；即使目标目录不可执行，也可造成磁盘占用与文件覆盖。

CVE/CWE 论证：对应 CWE-434（Unrestricted Upload of File with Dangerous Type）。外部可达性：上传入口为 HTTP 表单字段 uploaded，无需认证即可访问 044.php；利用链闭合：$_FILES['uploaded']['tmp_name'] → move_uploaded_file(..., $target_path) → 落盘至可控路径，中间无扩展名白名单、无 MIME 校验、无内容检测，第 9 行仅判断返回值。$target_path 的具体来源在给定片段外，属证据不足部分，不影响“缺少危险类型限制”这一核心弱点成立。

修复建议：1) 对上传文件实施扩展名白名单（如仅允许 .jpg/.png/.pdf），并基于服务端解析的真实 MIME 与文件头魔数二次校验，不信任客户端 Content-Type；2) 使用随机生成的文件名（如 bin2hex(random_bytes(16))）替代用户可控文件名，禁止路径分隔符与 .. 序列；3) 将上传目录置于 Web 根之外，或通过 Nginx/Apache 配置禁止该目录执行脚本（如 location ~ \.php$ { deny all; }）；4) 限制文件大小与数量，上传目录以最小权限运行，禁止覆盖已有文件；5) 对图片等可二次处理类型做重编码以剥离潜在载荷。

F-2 DVWA 044.php 无限制文件上传导致任意 PHP 文件写入 Web 目录（RCE）

high file_upload / CWE-434 · 置信度 0.88 · candidate / llm_inferred

位置：044.php:3-16

044.php 在收到 POST 参数 Upload 时，直接取 $_FILES['uploaded']['name'] 经 basename() 处理后拼接到 DVWA_WEB_PAGE_TO_ROOT."hackable/uploads/" 目录，并调用 move_uploaded_file 落盘。代码未做任何扩展名白名单、MIME/内容类型校验、文件内容检查、大小限制或随机化重命名，攻击者可上传 .php 文件到 Web 可访问的 hackable/uploads/ 目录，随后直接请求该文件由 PHP 解析执行，形成远程代码执行。

影响：攻击者可在 Web 根目录写入任意 PHP 文件并执行，获得 Web 服务器权限，进而读取配置/数据库凭据、横向移动，构成远程代码执行。

CVE/CWE 论证：CWE-434（Unrestricted Upload of File with Dangerous Type）。外部 HTTP 可达，无需认证即可触发（DVWA 默认部署），source（上传文件名/内容）到 sink（move_uploaded_file）链路在 044.php:3-9 完整闭合，无任何白名单或内容校验。

修复建议：对上传文件实施扩展名白名单（仅允许图片等）、校验真实 MIME 与文件头魔数、使用随机化文件名并去除原始扩展名、将上传目录置于 Web 根之外或禁止该目录执行 PHP（如 Nginx location 拒绝 .php），并限制文件大小。
