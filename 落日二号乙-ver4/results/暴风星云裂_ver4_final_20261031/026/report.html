F-1 026.php ping 功能通过 $_REQUEST['ip'] 拼接 shell_exec 导致命令注入（RCE）

critical command_injection / CWE-78 · 置信度 0.9 · candidate / llm_inferred

位置：026.php:5-14

脚本在收到 POST 参数 Submit 后，从 $_REQUEST['ip'] 读取用户输入 $target，未做任何白名单、转义或参数化处理，直接字符串拼接到 shell_exec('ping ' . $target)（Windows 分支）或 shell_exec('ping -c 4 ' . $target)（*nix 分支）。攻击者可通过在 ip 参数中注入 shell 元字符（如 ; | & ` $()）执行任意系统命令，获得服务器命令执行权限。

影响：未认证远程攻击者可在服务器上以 Web 进程权限执行任意系统命令，完全控制主机，读取/篡改数据，横向移动。

CVE/CWE 论证：CWE-78 OS 命令注入。外部 HTTP 可达、无需认证、source（$_REQUEST['ip']）到 sink（shell_exec）链路在 CODE PACK 内完整闭合，无任何净化环节。

修复建议：不要将用户输入拼接到 shell 命令。使用 escapeshellarg() 对 $target 转义，或改用白名单校验（如 filter_var($target, FILTER_VALIDATE_IP)）后再拼接；更佳做法是使用 proc_open 传参数数组避免 shell 解释。

F-2 026.php Windows 分支 ping 命令拼接导致 OS 命令注入（CWE-78）

critical command_injection / CWE-78 · 置信度 0.78 · candidate / rule_verified+llm

位置：026.php:8-10

攻击者通过 HTTP query 参数 `ip` 提供输入，026.php:5 将其读入 `$target`；026.php:8 用 `stristr(php_uname('s'),'Windows NT')` 判断运行平台，命中 Windows 分支后，026.php:10 执行 `$cmd = shell_exec( 'ping ' . $target );`。`$target` 未经任何转义、白名单校验或参数化，直接以字符串拼接方式进入 shell 命令行，因此 `&`、`|`、`&&` 等 Windows shell 元字符可截断 ping 命令并追加任意命令。代码片段中未见 escapeshellarg/escapeshellcmd 或输入白名单，校验缺失即为绕过原因。

影响：远程命令执行（RCE）：攻击者以 Web 服务进程权限在目标主机执行任意系统命令，可读取/篡改应用与系统文件、窃取数据库与配置凭据、建立持久化后门，并可作为横向移动跳板。无需认证即可通过单个 GET 请求触发。

CVE/CWE 论证：CWE-78（OS Command Injection）：外部可控输入 `ip` 经 `$target` 未净化拼接进 `shell_exec`，形成完整 source→sink 链；该脚本为 Web 可达 PHP 页面，攻击者仅需构造 query 参数即可触发，无需认证、无需本地访问，利用链闭合。

修复建议：不要用 shell 拼接执行 ping：改用参数数组形式（如 proc_open/exec 传数组）或 PHP 原生网络函数；若必须调用外部程序，对 `$target` 做严格白名单校验（仅允许 IPv4/IPv6 字面量，用 filter_var(FILTER_VALIDATE_IP) 校验）并配合 escapeshellarg；同时以最小权限账户运行 Web 服务，禁用不必要的 shell 函数。
