F-1 046.php 会话标识由自增计数器派生，可预测（CWE-330）

high weak_id / CWE-330 · 置信度 0.7 · candidate / rule_verified+llm

位置：046.php:5-6

攻击者通过向 046.php 发起 POST 请求（046.php:5 仅校验 REQUEST_METHOD == "POST"，无认证要求）驱动会话状态机：046.php:6 判断 $_SESSION['last_session_id_high'] 是否已设置，未设置时在 046.php:7 初始化为 0，随后 046.php:9 每次请求自增 1，046.php:10 以 md5 包装该值，046.php:11 写入名为 dvwaSession 的 Cookie。校验无效的根因是：标识的熵完全来自一个单调递增的小整数，既不使用 random_bytes/uniqid 等随机源，也不绑定服务端密钥；攻击者只需知道初始值 0 与自增步长 1，即可精确预测任意后续请求的 Cookie 值，无需任何暴力破解。

影响：会话固定/会话预测：攻击者可预先算出下一个 dvwaSession 值并植入受害者浏览器（会话固定），或在观察到一次合法值后推算后续值，从而劫持会话、以受害者身份访问 /vulnerabilities/weak_id/ 相关功能，造成越权与数据泄露。不涉及命令执行或文件系统操作。

CVE/CWE 论证：CWE-330（Use of Insufficiently Random Values）：安全决策所依赖的会话标识来自可预测的计数器而非 CSPRNG。外部可达性：046.php:5 的 POST 分支对外暴露，无需认证；利用链闭合：POST → 046.php:6/7 初始化 → 046.php:9 自增 → 046.php:10 派生 → 046.php:11 下发 Cookie → 攻击者预测/固定。与 SEM-7da0188b59a9 的区别在于本条根因是随机性不足（CWE-330），MD5 只是放大可预测性的包装层。

修复建议：1) 使用 CSPRNG 生成会话标识：bin2hex(random_bytes(32))，或直接依赖 PHP 原生 session 机制并调用 session_regenerate_id(true) 在登录后轮换；2) 禁止以自增计数器、时间戳、mt_rand 等可预测源派生安全令牌；3) 服务端保存令牌→用户的映射并校验来源 IP/UA 指纹，设置绝对与空闲超时；4) 下发 Cookie 时启用 secure、httponly 与 SameSite，降低固定攻击面。

F-2 046.php 使用 MD5 派生会话 Cookie 值（CWE-327 归类偏差，实为 CWE-328 弱哈希）

medium weak_crypto / CWE-327 · 置信度 0.76 · candidate / rule_verified+llm

位置：046.php:9-10

攻击者无需输入任何参数：服务端在 046.php:9 将 $_SESSION['last_session_id_high'] 自增，随后在 046.php:10 用 md5($_SESSION['last_session_id_high']) 生成 $cookie_value，并在 046.php:11 通过 setcookie("dvwaSession", $cookie_value, time()+3600, "/vulnerabilities/weak_id/", $_SERVER['HTTP_HOST'], false, false) 下发。校验无效的原因在于：被哈希的输入本身是一个从 0 开始的小整数计数器（046.php:7 初始化为 0），MD5 只是对该整数做无密钥的单向压缩，不引入任何熵，也不提供完整性保护；攻击者可直接对 0、1、2… 预先计算 MD5 字典，完全枚举 Cookie 值空间。此外 setcookie 的 secure 与 httponly 两个标志位均显式为 false（046.php:11），Cookie 可在明文 HTTP 下传输并被脚本读取。

影响：会话标识可预测/可伪造：攻击者枚举 md5(0..N) 即可猜出合法 dvwaSession 值，配合 secure=false、httponly=false 可在明文信道或 XSS 场景下窃取并复用会话，导致身份冒用与越权访问 /vulnerabilities/weak_id/ 下的受保护功能。不构成 RCE 或文件读写。

CVE/CWE 论证：CWE-328（Use of Weak Hash）：MD5 用于生成安全敏感的会话令牌，属口令/令牌类安全用途，抗碰撞与抗原像强度不足。外部可达性：046.php:5 仅要求 REQUEST_METHOD == "POST"，无需认证即可触发令牌生成与下发；利用链闭合：POST 请求 → 计数器自增（046.php:9）→ md5 派生（046.php:10）→ setcookie 下发（046.php:11）→ 攻击者离线枚举比对。注意：本条原始归类为 weak_crypto（CWE-327），按证据应更正为 weak_hash（CWE-328），算法为 MD5 而非 DES/ECB 类加密算法缺陷。

修复建议：1) 停止使用 MD5 派生会话标识，改用 CSPRNG：random_bytes(32) 或 session_regenerate_id(true) 生成服务端会话 ID；2) 若必须下发自定义 Cookie，使用 hash_hmac('sha256', $value, $server_side_secret) 并保证 $value 含足够熵；3) 将 setcookie 的 secure 与 httponly 置为 true，并补充 SameSite=Lax/Strict；4) 服务端维护令牌白名单并设置短有效期与一次性使用，避免纯计数器派生。
