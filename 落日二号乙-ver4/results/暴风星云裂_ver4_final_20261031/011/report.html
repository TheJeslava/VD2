F-1 011.php 登录接口 username 参数 SQL 注入（可绕过认证）

critical sql_injection / CWE-89 · 置信度 0.9 · candidate / llm_inferred

位置：011.php:5-13

011.php 第 3 行在 $_GET['Login'] 存在时进入登录逻辑，第 5 行直接取 $_GET['username'] 赋给 $user，未做任何转义或参数化；第 12 行将 $user 直接字符串拼接进 SELECT 语句，第 13 行通过 mysqli_query 执行。攻击者可在 username 中注入 SQL 语法（如 ' OR '1'='1' -- -）改变 WHERE 条件，使查询恒真并返回 users 表首行，从而在不知道口令的情况下通过第 15 行 mysqli_num_rows == 1 的判定，进入“password protected area”。password 参数虽经 md5() 处理（第 9 行），但 md5 输出为固定 32 位十六进制，无法注入，因此注入点唯一在 username。

影响：未认证攻击者可直接绕过登录进入受保护区域，并可进一步通过 UNION/布尔盲注读取 users 表全部用户名与口令哈希，导致账户接管与数据泄露。

CVE/CWE 论证：CWE-89 SQL 注入。外部 GET 参数 username 未经转义直接拼接进 SQL 并由 mysqli_query 执行，无需认证即可触发，利用链在 CODE PACK 内完全闭合（011.php:5 → 12 → 13 → 15）。

修复建议：使用预处理语句（mysqli_prepare + bind_param）绑定 username 与 password；对输入做类型与长度校验；关闭 die() 中的数据库错误回显以避免信息泄露。

high brute_force / CWE-307 · 置信度 0.55 · candidate / rule_verified+llm

011.php:3 通过 `isset($_GET['Login'])` 进入登录流程，011.php:5 读取 `username`、011.php:8 读取 `password`，随后直接查询比对。代码中未见失败计数、账户锁定、验证码、速率限制或延迟机制，攻击者可对同一接口无限次提交口令猜测。证据为 011.php:2-3 的登录入口与后续无防护的查询逻辑；运行时是否另有网关限流证据不足。

F-3 011.php 使用 MD5 处理口令（CWE-328 弱哈希）

medium weak_crypto / CWE-327 · 置信度 0.76 · candidate / rule_verified+llm

位置：011.php:8-9

011.php:8 从 GET 参数 `password` 读取明文口令，011.php:9 直接调用 md5($pass) 生成摘要后用于 011.php:12 的登录比对。MD5 为快速、无盐、抗碰撞性已被攻破的哈希算法，用于口令存储/校验属安全用途误用。此处为配置/实现型弱点，不依赖 HTTP 污点链，证据为 011.php:9 的 `md5(` 调用原文。

影响：若数据库泄露，攻击者可用彩虹表/GPU 高速爆破快速还原用户口令；MD5 无盐导致相同口令产生相同摘要，可做批量比对与撞库，进而横向登录其他系统。

CVE/CWE 论证：CWE-328（弱哈希），非 CWE-327（后者指 DES/ECB 等加密算法误用）。外部可达性：登录接口公开，攻击者提交任意口令即触发 md5 计算；弱点根因在 011.php:9 的算法选择，无需额外前置条件。

修复建议：改用专为口令设计的慢哈希算法（bcrypt/Argon2id/PBKDF2），并为每个用户生成独立随机盐；迁移时对存量 MD5 摘要做透明升级；禁止在安全用途中使用 MD5/SHA-1。

F-4 011.php 登录成功页 username 反射型 XSS

medium xss / CWE-79 · 置信度 0.7 · candidate / llm_inferred

位置：011.php:21-22

第 21 行将 $user（来自 $_GET['username']，第 5 行）直接拼接进 HTML 输出 $html，未做 htmlspecialchars 等输出编码。虽然进入该分支需要 SQL 查询成功（可通过同文件的 SQL 注入使条件恒真），但一旦查询返回一行，攻击者控制的 username 原样反射到页面，形成反射型 XSS。此外第 22 行将数据库 avatar 字段拼入 img src，若 avatar 可被低权限用户写入则存在存储型风险，但 CODE PACK 内无写入点证据，故仅报告 username 反射链。

影响：可在受害者浏览器上下文执行任意 JS，窃取会话或发起 CSRF 式操作；结合 SQL 注入可稳定触发。

CVE/CWE 论证：CWE-79 反射型 XSS。username 从 GET 参数到 HTML 输出无编码，链在 CODE PACK 内闭合（011.php:5 → 21）。

修复建议：输出前对 $user 使用 htmlspecialchars($user, ENT_QUOTES, 'UTF-8')；对 avatar 做 URL 白名单校验。
