F-1 044.php 不安全文件上传（CWE-434）：上传文件被直接移动到目标路径，缺少类型/扩展名校验

critical file_upload / CWE-434 · 置信度 0.7 · candidate / rule_verified+llm

位置：044.php:7-9

攻击者通过 HTTP 请求向 044.php 提交 multipart 表单，文件字段名为 `uploaded`。脚本在 044.php:9 直接调用 `move_uploaded_file( $_FILES['uploaded']['tmp_name'], $target_path )`，把 PHP 临时文件移动到 `$target_path` 指定的位置。输入来源是 `$_FILES['uploaded']`（文件名、临时路径、内容均由客户端控制），中间没有经过任何扩展名白名单、MIME 校验、`getimagesize()` 内容校验或文件名规范化；`$target_path` 在给出的片段（044.php:7-9）中未展示其构造过程，因此无法确认其是否包含上传目录前缀或是否由用户可控文件名拼接，这一点属于证据不足。由于缺少对上传内容与扩展名的校验，攻击者可以上传 `.php` 等可执行脚本，若目标目录位于 Web 可访问路径且服务器允许执行该扩展名，则文件落地后即可被请求执行。

影响：若上传目录可被 Web 访问且允许脚本执行，攻击者可上传 PHP 等可执行文件并获得远程代码执行（RCE），进而读取/篡改服务器文件、窃取数据库凭据、以内网身份横向移动；即使不可执行，也可造成任意文件写入、磁盘占满、托管恶意内容（钓鱼/恶意软件分发）等后果。

CVE/CWE 论证：对应 CWE-434（Unrestricted Upload of File with Dangerous Type）。外部可达性：044.php 为 Web 端点，上传字段 `uploaded` 由任意未认证 HTTP 客户端提交，无需登录或特权；利用链闭合：`$_FILES['uploaded']['tmp_name']` → `move_uploaded_file()` → `$target_path`，中间无白名单/内容校验，属于典型的“客户端可控文件直接落盘”。注意：`$target_path` 的构造在给定片段中不可见，若其被限制在不可执行目录或做了扩展名重写，实际可利用性会下降，故本条为基于源码的推断（llm_inferred），未做动态验证。

修复建议：1) 使用扩展名白名单（如仅 jpg/png/gif/pdf）并同时校验 MIME 与文件头（`finfo_file`/`getimagesize`），拒绝双扩展名与 `.php`、`.phtml`、`.phar` 等；2) 不要使用客户端提供的文件名，改为服务端生成随机文件名（如 `bin2hex(random_bytes(16))` + 白名单后缀），并对 `$target_path` 做 `realpath()` 规范化后校验其位于预期上传目录内；3) 将上传目录置于 Web 根之外，或通过 Web 服务器配置禁用该目录的脚本执行（如 Nginx `location ~ \.php$ { deny all; }`）；4) 限制文件大小与数量，上传目录以最小权限运行，禁止执行位；5) 对上传文件做病毒/内容扫描并按需重编码图片。

F-2 DVWA 044.php 无限制文件上传导致任意 PHP 文件写入 Web 目录（RCE）

high file_upload / CWE-434 · 置信度 0.9 · candidate / llm_inferred

位置：044.php:3-16

044.php 在收到 POST 参数 Upload 时，直接把 $_FILES['uploaded']['name'] 经 basename() 处理后拼接到 DVWA_WEB_PAGE_TO_ROOT."hackable/uploads/" 目录，并调用 move_uploaded_file() 落盘。代码未校验扩展名、MIME、文件内容，也未做白名单或重命名，攻击者可上传 .php 文件到 Web 可访问目录，随后直接请求该文件即可在服务器执行任意 PHP 代码，形成远程代码执行。basename() 仅剥离路径部分，不限制扩展名，无法阻止 webshell 上传。

影响：攻击者可在服务器写入并执行任意 PHP 代码，完全控制 Web 应用与主机（RCE）。

CVE/CWE 论证：CWE-434 Unrestricted Upload of File with Dangerous Type。外部可直接 POST 触发，无需认证（取决于部署），source→sink 链在 044.php:3-9 完整闭合，落盘路径可由响应回显确认。

修复建议：使用扩展名白名单（仅允许图片等）、校验 MIME 与文件魔数、随机重命名文件、将上传目录置于 Web 根之外或禁用该目录 PHP 执行（如 php_flag engine off / location 拒绝 .php）。
