# VulnCatcher 漏洞研究工作台

适配 VD2 ver5 的课程实验前端。解压整个文件夹，使用现代浏览器双击打开 `index.html`。HTML、CSS、JavaScript、字体回退和报告资源均可离线使用。

## 演示顺序

1. 进入 **ZIP 源码分析**，点击 **载入示例 ZIP**，清空可选的关联地址，点击 **开始挖掘**。执行监视器会逐项显示模块状态。
2. 在 **漏洞与 POC** 按严重度筛选，或搜索 CWE、标题、文件名。选中一条发现，切换右侧的 **POC 工件**，可选择文件并复制内容。点击 **完整挖掘报告** 打开该样例的 HTML 报告。
3. 点击 **验证漏洞**，选择 **使用示例靶场**，再点击 **启动验证**。监视器依次展示 POC 收集、沙箱执行、证据研判与报告生成。在 **验证结果** 列表中选择发现，可对照基线与探测 HTTP 状态码，**验证报告** 打开原始文本报告。
4. 切换 **URL 动态探测**，只输入一个 HTTP(S) 地址即可演示 URL 管线。保留 ZIP 模式并补填地址则演示 ZIP + AWVS 探针关联。
5. 右上角齿轮或导航中的 **智能体设置** 可配置各模块的 LLM 辅助，以及攻击面测绘、深挖、二次注入与隐性逻辑模块的启停。必经模块标有“固定”。设置从下一次任务开始生效。
6. **任务历史** 保存当前浏览器最近 30 次演示的名称、输入地址、设置和进度。刷新页面后可以继续回放。在禁止本地存储的浏览器中，记录仅保留到关闭或刷新页面。

也可以点击 **样例档案**，直接打开三种场景的历史样例。执行监视器支持展开阶段，查看包含的模块、当前状态和跳过项。

## 数据与展示范围

- 此版本只运行在浏览器中。选择的 ZIP 只读取文件名与大小，输入的目标地址只作为任务标签。演示不向目标发起网络请求。
- 三个样例整理自 VD2 提交 `a37995ddbc5a341fc6197c77094c5490953bf3f9` 的 VulnCatcher 与 VulnCatcher-Verify 在本地实验环境的输出。ZIP 样例包含上游自检用的两个 Java 片段，URL 样例来自一个本地反射输入的 HTTP 端点。示例中的目录和端口已经标准化。
- ZIP 有 3 条发现，URL 有 1 条，组合模式有 4 条。研判结论保留该次实验的证据。开关会改变演示步骤和 LLM 状态标记，完整报告始终对应其注明的固定样例。
- 可将整个文件夹直接放入静态站点托管。任务历史通过浏览器本地存储维护。

## 文件

`index.html` 为入口，`app.js` 管理交互、回放和历史，`review.js` 绘制管线、档案与证据面板，`style.css` 提供响应式布局。`samples.js` 保存逐条样例，`samples/` 保存完整报告。`lab-source.zip` 为可选择的 ZIP 样本。
