F-1 025.php ping 功能通过 $_REQUEST['ip'] 拼接 shell_exec 导致命令注入（黑名单可绕过）

critical command_injection / CWE-78 · 置信度 0.9 · candidate / llm_inferred

位置：025.php:5-30

025.php 在收到 POST 参数 Submit 后，从 $_REQUEST['ip'] 读取用户输入（第 5 行），仅用 str_replace 对黑名单字符（||、&、;、'| '、-、$、(、)、`）做删除（第 8-21 行），随后把结果直接拼接到 shell_exec('ping -c 4 ' . $target)（*nix，第 30 行）或 shell_exec('ping ' . $target)（Windows，第 26 行）执行。黑名单存在多处缺陷：只删除 '| '（竖线加空格）而不删除单独的 '|'，因此可用 '|' 直接管道到任意命令；只删除 '||' 与 '&'，未处理换行符 %0a；删除 '-' 会破坏 ping 参数但不影响注入；删除 '$'、'('、')'、'`' 只阻断部分子 shell 语法。攻击者可用 '127.0.0.1|id' 或 '127.0.0.1 id' 绕过黑名单，实现任意命令执行，完全控制 Web 服务器进程权限。

影响：攻击者无需认证即可在 Web 服务器上以 Web 进程权限执行任意系统命令，可读取敏感文件、横向移动、植入后门，导致服务器完全失陷。

CVE/CWE 论证：CWE-78 OS 命令注入。外部可达（HTTP POST 参数 ip），无需认证，source→sink 链完整闭合：$_REQUEST['ip'] → str_replace 黑名单（可绕过）→ shell_exec 拼接执行。黑名单未覆盖单独 '|' 与换行符，绕过确定。

修复建议：不要拼接 shell 命令；使用 escapeshellarg($target) 对参数转义，或改用白名单校验 IP 格式（filter_var($target, FILTER_VALIDATE_IP)），并避免使用 shell_exec 调用外部 ping，改用 PHP 原生网络函数。
