# 隐性逻辑模块复查记录

审查对象：首次实现提交 `cc29898`。本轮通过独立静态反例、模拟模型故障、受控本地 HTTP 实验和完整回归核对实际行为。以下问题均已复现，并在相应代码中修正；源码输入仅被解析，不执行其中的任意代码。

## 修复的判定问题

| 复现问题 | 原行为 | 修正 |
|---|---|---|
| 条件表达式内重新绑定会话、嵌套定义的默认值/装饰器修改状态 | 可能继续使用旧校验而给出 guarded | 对未建模的表达式和定义副作用保留 needs_context |
| 任意对象的 `.get()` 或被覆盖的 `int` 等名字 | 可能被当成无副作用的读取 | 限定支持的读取语义，未知调用与转换保留缺口 |
| 未知类型数值先拒绝 `<= 0` | 直接推导 `> 0`，忽略 NaN 等情况 | 不在没有类型依据时使用该比较转换；直接检查正数的样本仍正常识别 |
| 同一行存在两次敏感调用 | 行号相同导致判定合并 | ID 包含调用的列位置；前一次操作的副作用也会使后续检查保守降级 |
| PHP 页面文本、字符串、heredoc/nowdoc 中的代码示例 | 可能被识别成真实验证码/SQL 操作 | 识别 PHP 代码区域并屏蔽文字区域，SQL 赋值前缀必须位于实际代码中 |
| PHP 无条件退出或明确常假分支之后的 SQL | 可能被报告成可到达的操作 | 排除可确定的不可达操作 |
| PHP 最终步骤之外的前置校验 | 可能误认为没有服务端保护 | 对未知外层保护保留 needs_context，仍保留原始 014/015 的静态识别 |
| 直接调用分析 API 时传入错误的规则字段类型 | 某些错误值可能被当作有效配置或导致异常 | 校验上下文标记、可信输入和参数绑定等字段类型 |

## 修复的接入与实验问题

| 复现问题 | 原行为 | 修正 |
|---|---|---|
| 两条独立业务规则指向同一操作或相邻代码 | 汇总器按“类型 + 邻近行号”丢弃一条 | 保留不同专属判定 ID；只合并已明确确认同一来源的提示 |
| 可选模型复核抛出异常 | 已分析的静态结果没有转成 Finding | 记录模型错误并继续生成静态 Finding |
| 会话隔离实验中，准备阶段的验证码实际上没有成功 | 最终请求被拒绝仍可能算实验通过 | 准备阶段也检查 HTTP、业务状态与会话状态；最终通过要求所有前提成立 |
