medium xss / CWE-79 · 置信度 0.9 · candidate / externally_corroborated

位置：052.php:6-11

052.php 第 6 行从 $_GET['name'] 读取外部输入，第 8 行仅用正则 /<(.*)s(.*)c(.*)r(.*)i(.*)p(.*)t/i 删除形如 <...script...> 的子串，第 11 行将结果直接拼进 "<pre>Hello {$name}</pre>" 输出，未做 htmlspecialchars 等 HTML 实体编码；第 3 行还主动发送 X-XSS-Protection: 0 关闭浏览器 XSS 过滤器。由于正则只匹配一次且不递归，攻击者可用嵌套/拆分标签（如 <scr<script>ipt>alert(1)</script> 或 <img src=x onerror=alert(1)>）绕过黑名单，使浏览器解析出可执行脚本，构成反射型 XSS。

影响：攻击者可在受害者浏览器上下文执行任意 JavaScript，窃取会话/凭证、伪造操作或进行钓鱼；X-XSS-Protection: 0 进一步降低浏览器侧防护。

CVE/CWE 论证：CWE-79 跨站脚本。外部 GET 参数 name 无需认证即可控制，经可绕过的黑名单过滤后直接进入 HTML 输出，source→sink 链在 CODE PACK 内完整闭合。

修复建议：输出前使用 htmlspecialchars($name, ENT_QUOTES, 'UTF-8') 进行 HTML 实体编码；移除 X-XSS-Protection: 0；不要依赖黑名单正则过滤，改用白名单或上下文编码。
