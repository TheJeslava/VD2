F-1 045.php 不安全文件上传导致任意文件写入（CWE-434）

critical file_upload / CWE-434 · 置信度 0.78 · candidate / rule_verified+llm

位置：045.php:16-18

攻击者通过 HTTP 文件上传表单字段 `uploaded` 提交文件，PHP 将其暂存于 `$_FILES['uploaded']['tmp_name']`（045.php:18）。代码在 045.php:18 直接调用 `move_uploaded_file($_FILES['uploaded']['tmp_name'], $target_path)` 将临时文件移动到 `$target_path`，在给出的代码片段（045.php:16-18）中未见对文件扩展名、MIME 类型、文件内容或目标路径的任何白名单校验，也未见对 `$target_path` 的规范化与目录限制。因此上传文件的原始名称/类型未经净化即被持久化落盘，校验环节缺失，污点从 `$_FILES['uploaded']` 直达文件写入汇点。注意：`$target_path` 的赋值语句不在本次给出的片段范围内，其具体构造方式（是否拼接用户可控文件名）证据不足，需结合 045.php 更早行确认。

影响：攻击者可上传任意内容与扩展名的文件（如 .php/.phtml/.phar），若上传目录位于 Web 可访问路径且允许脚本执行，则可进一步实现远程代码执行（RCE）；即使不可执行，也可造成任意文件写入、覆盖已有文件、磁盘占满，或作为钓鱼/恶意载荷托管点。属于高危的任意文件上传。

CVE/CWE 论证：对应 CWE-434（Unrestricted Upload of File with Dangerous Type）。外部可达性：上传入口为 HTTP 表单字段 `uploaded`，无需认证即可访问该脚本（片段中未见任何鉴权/会话校验）。利用链闭合：`$_FILES['uploaded']['tmp_name']` → `move_uploaded_file(..., $target_path)`（045.php:18），中间无扩展名/类型/内容校验，落盘即完成。证据等级为源码推断（llm_inferred），未做动态验证；`$target_path` 的构造细节因不在片段内而证据不足。

修复建议：1) 对上传文件建立扩展名与 MIME 类型双重白名单，仅允许业务必需的类型（如 jpg/png/pdf），并校验文件魔数而非仅信任 Content-Type；2) 使用服务端生成的随机文件名（如 UUID）替代客户端文件名，禁止路径分隔符与 `..`；3) 将上传目录置于 Web 根之外，或配置该目录禁止脚本执行（如 Nginx `location ~ \.php$ { deny all; }`）；4) 限制文件大小与数量，落盘后设置最小权限（非可执行）；5) 对图片等可做二次编码/重采样以剥离潜在载荷；6) 上传接口增加认证与 CSRF 防护。

F-2 DVWA 上传端点 045.php 仅校验客户端可控的 MIME 类型，可上传任意 PHP 脚本并导致远程代码执行

high file_upload / CWE-434 · 置信度 0.88 · candidate / externally_corroborated

位置：045.php:3-26

045.php 通过 $_FILES['uploaded']['type']（即 HTTP 请求中的 Content-Type，完全由客户端控制）判断文件是否为图片，未使用 getimagesize()/finfo 等服务端内容检测，也未校验扩展名。攻击者把 PHP 脚本的 Content-Type 伪造成 image/jpeg 并保持体积小于 100000 字节，即可通过校验；随后 move_uploaded_file() 以 basename(原始文件名) 将其写入 DVWA_WEB_PAGE_TO_ROOT."hackable/uploads/"，文件名与扩展名均保留（如 shell.php）。该目录位于 Web 根下，直接请求即可执行任意 PHP 代码，形成 RCE。

影响：任意文件上传导致 Web 服务器上的远程代码执行，攻击者可完全控制应用与主机（在 Web 进程权限内）。

CVE/CWE 论证：CWE-434 无限制危险类型文件上传。外部可直接 POST 触发，脚本无认证/授权检查，Content-Type 校验可被请求头伪造绕过，链闭合至 move_uploaded_file 落盘 Web 目录。

修复建议：使用 finfo/getimagesize 做服务端内容检测；对扩展名与 MIME 双重白名单；上传目录置于 Web 根之外或禁用脚本执行；重命名为随机名并去除原始扩展名。
