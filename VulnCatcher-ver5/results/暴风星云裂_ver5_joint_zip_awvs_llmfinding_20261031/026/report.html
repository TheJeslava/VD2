F-1 026.php ping 功能通过 $_REQUEST['ip'] 拼接 shell_exec 导致命令注入（RCE）

critical command_injection / CWE-78 · 置信度 0.93 · candidate / externally_corroborated

位置：026.php:3-18

026.php 在收到 POST 参数 Submit 后，直接把 $_REQUEST['ip'] 拼进 shell_exec('ping -c 4 ' . $target)（Windows 分支为 'ping ' . $target）。$target 未做任何白名单、转义（escapeshellarg/escapeshellcmd）或类型校验，攻击者用 ; | & ` $() 等 shell 元字符即可在服务器上执行任意命令。由于 $_REQUEST 同时接受 GET/POST/Cookie，攻击面更宽。

影响：未认证远程攻击者可在 Web 服务器进程权限下执行任意系统命令，完全控制主机，读取敏感文件、横向移动。

CVE/CWE 论证：CWE-78 OS 命令注入。source（$_REQUEST['ip']）到 sink（shell_exec 字符串拼接）链路完整、无过滤，外部无需认证即可触发，属典型 CVE 级 RCE。

修复建议：不要将用户输入拼入 shell 命令；使用 escapeshellarg($target) 并对 ip 做严格 IP 格式校验（filter_var FILTER_VALIDATE_IP），或改用不经过 shell 的 API。

F-2 026.php Windows 分支 ping 命令拼接导致 OS 命令注入（CWE-78）

critical command_injection / CWE-78 · 置信度 0.78 · candidate / rule_verified+llm

位置：026.php:8-10

攻击者通过 HTTP 查询参数 `ip` 提供输入，该参数在 026.php:5 被读入变量 `$target`。026.php:8 使用 `stristr(php_uname('s'), 'Windows NT')` 判断运行平台，命中 Windows 分支后，026.php:10 执行 `$cmd = shell_exec( 'ping ' . $target );`，将 `$target` 未经任何转义、白名单校验或参数化直接拼接到 shell 命令字符串中。由于 `shell_exec` 会把整串交给系统 shell 解释，`$target` 中的 `&`、`|`、`&&`、`;` 等元字符会被 shell 当作命令分隔符执行，代码中不存在 escapeshellarg/escapeshellcmd 或输入格式校验，因此校验无效。最终危险操作是 026.php:10 的 `shell_exec` 命令执行。

影响：远程未认证攻击者可在目标 Windows 主机上以 Web 服务进程权限执行任意系统命令，导致服务器完全失陷、敏感数据泄露、横向移动与持久化。属于 RCE 级别影响。

CVE/CWE 论证：CWE-78（OS 命令注入）。外部可达性：注入点为 HTTP query 参数 `ip`，无需认证即可访问该脚本；利用链闭合：`ip` → `$target`（026.php:5）→ 字符串拼接（026.php:10）→ `shell_exec` 执行，中间无净化函数。该分支仅在 Windows 平台触发，属平台相关但完全可由攻击者控制输入。

修复建议：不要用字符串拼接构造 shell 命令。改用参数数组形式（如 `proc_open`/`exec` 传数组）或对 `$target` 做严格白名单校验（仅允许 IPv4/IPv6 字面量，用 `filter_var($target, FILTER_VALIDATE_IP)` 验证），并在必须拼接时使用 `escapeshellarg($target)`；同时以最小权限账户运行 Web 服务。

F-3 026.php *nix 分支 ping 命令拼接导致 OS 命令注入（CWE-78）

critical command_injection / CWE-78 · 置信度 0.78 · candidate / rule_verified+llm

位置：026.php:12-14

攻击者通过 HTTP 查询参数 `ip` 提供输入，026.php:5 将其读入 `$target`。当 026.php:8 的平台判断不成立（非 Windows，即 *nix 分支）时，026.php:14 执行 `$cmd = shell_exec( 'ping -c 4 ' . $target );`，`$target` 未经转义或白名单校验直接拼入 shell 命令。`shell_exec` 将整串交由 `/bin/sh` 解释，`;`、`|`、`&&`、`$()`、反引号等元字符可注入并执行任意命令；代码中无 escapeshellarg/escapeshellcmd 或格式校验，故校验无效。最终危险操作为 026.php:14 的 `shell_exec`。

影响：远程未认证攻击者可在目标 Linux/Unix 主机上以 Web 服务进程权限执行任意命令，实现 RCE、读取敏感文件、反弹连接与进一步提权，导致服务器失陷。

CVE/CWE 论证：CWE-78（OS 命令注入）。外部可达性：注入点为 HTTP query 参数 `ip`，无需认证；利用链闭合：`ip` → `$target`（026.php:5）→ 拼接（026.php:14）→ `shell_exec` 执行，无净化环节。该分支在 *nix 平台触发，是常见部署环境，实际可利用性高。

修复建议：使用参数数组方式调用外部程序（`proc_open`/`exec` 传数组参数），或对 `$target` 使用 `filter_var($target, FILTER_VALIDATE_IP)` 严格校验为 IP 字面量；若必须拼接则使用 `escapeshellarg($target)`。同时限制 Web 进程权限并禁用不必要的 shell 函数。
