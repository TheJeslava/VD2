位置：034.php:3-6

脚本从 $_GET['redirect'] 取值，仅用 strpos($_GET['redirect'], "info.php") !== false 判断是否包含子串 "info.php"，随后直接 header("location: " . $_GET['redirect']) 跳转。该校验只要求 URL 任意位置出现 "info.php" 子串，攻击者可构造 https://evil.example/info.php 或 //evil.example/info.php 等外部地址，使 strpos 返回非 false，从而通过校验并被 302 重定向到攻击者控制的站点。缺少对目标主机/协议的白名单校验与相对路径限制，构成开放重定向（CWE-601）。

影响：攻击者可借助受信任域名的链接将用户重定向到钓鱼/恶意站点，用于凭据窃取或社工攻击。

CVE/CWE 论证：CWE-601 开放重定向；外部无需认证即可触发，source→sink 链在 034.php:3-5 完整闭合，校验仅子串匹配可被绕过。

修复建议：对 redirect 目标做严格白名单：仅允许相对路径或固定主机，解析 URL 后校验 host 与 scheme，拒绝外部域与 // 开头值。
